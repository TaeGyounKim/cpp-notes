- 다루는 것: `{}` 안에 적어 값의 출력 모양을 다듬는 방법
- 배우는 요소: 너비, 정렬과 채움 문자, 부호, `#`, 타입, 정밀도, `0`, `L`
- 모두 `std::format`, `std::print`, `std::println`에서 똑같이 씀 <Badge text="C++20" />

## 형식 지정자의 구조

- **형식 지정자** (format specifier): 치환 필드에서 콜론(`:`) 뒤에 적는 부분. 값을 어떤 모양으로 출력할지 정함 <CppRef path="cpp/utility/format/spec" />
- 전체 구조. 대괄호로 묶은 부분은 모두 생략할 수 있고, **적는 순서는 이 순서 그대로**

```text
{번호:[채움][정렬][부호][#][0][너비][.정밀도][L][타입]}
```

| 부분 | 예 | 하는 일 |
| --- | --- | --- |
| 채움 + 정렬 | `*<`, `>`, `_^` | 남는 칸을 무엇으로 채우고 어느 쪽으로 붙일지 |
| 부호 | `+`, `-`, 빈칸 | 양수의 부호를 어떻게 할지 |
| `#` | `#` | 진법 접두어 등 대체 형식 |
| `0` | `0` | 숫자 앞을 0으로 채움 |
| 너비 | `8`, `{}` | 최소 몇 칸을 차지할지 |
| 정밀도 | `.2`, `.{}` | 소수 자릿수 또는 글자 수 |
| `L` | `L` | 로케일에 맞춘 형식 |
| 타입 | `d`, `x`, `f`, `s` | 어떤 표현으로 출력할지 |

- 예: `{:*>+10.2f}` → 채움 `*`, 정렬 `>`, 부호 `+`, 너비 `10`, 정밀도 `.2`, 타입 `f`

## 너비, 정렬, 채움 문자

- **너비** (width): 그 값이 차지할 **최소** 칸 수. 값이 더 길면 잘리지 않고 그대로 나옴
- **정렬** (align)

| 기호 | 뜻 | 기본으로 쓰이는 타입 |
| --- | --- | --- |
| `<` | 왼쪽 정렬 | 문자열을 비롯한, 숫자가 아닌 타입 |
| `>` | 오른쪽 정렬 | 정수, 부동소수점 |
| `^` | 가운데 정렬 | |

- **채움 문자** (fill): 남는 칸을 채울 글자. 정렬 기호 **앞에** 적음. 생략하면 공백
  - `{:_>7}`: 오른쪽 정렬, 남는 칸은 `_`
- 가운데 정렬에서 남는 칸이 홀수면 오른쪽에 한 칸이 더 감
- 너비가 없으면 정렬과 채움 문자는 아무 효과가 없음
- **동적 너비** (dynamic width): 너비 자리에 `{}`를 적으면 인수에서 너비를 받음
  - `{:{}}`: 다음 인수가 값, 그다음 인수가 너비
  - `{1:{0}}`: 1번 인수가 값, 0번 인수가 너비

## 부호, #, 타입

### 부호

| 기호 | 양수 | 음수 |
| --- | --- | --- |
| `-` (기본) | 부호 없음 | `-` |
| `+` | `+` | `-` |
| 빈칸 | 빈칸 한 칸 | `-` |

- 빈칸을 쓰는 이유: 양수와 음수를 세로로 나란히 출력할 때 자릿수가 맞음

### 타입

- 값을 어떤 표현으로 출력할지 정하는 글자. 형식 지정자의 맨 끝에 적음

| 값의 타입 | 쓸 수 있는 타입 글자 | 생략하면 |
| --- | --- | --- |
| 정수 | `d` 10진수, `b` / `B` 2진수, `o` 8진수, `x` / `X` 16진수 | `d` |
| 부동소수점 | `f` / `F` 고정 소수점, `e` / `E` 지수 표기, `g` / `G` 둘 가운데 알맞은 쪽, `a` / `A` 16진 표기 | 값을 되살릴 수 있는 가장 짧은 표현 |
| `bool` | `s` 글자로(`true`, `false`), `d` 등 정수 타입 글자는 1 / 0으로 | `s` |
| 문자 | `c` 글자로, `d` 등 정수 타입 글자는 문자 코드로, `?` 이스케이프해서 | `c` |
| 문자열 | `s` 그대로, `?` 이스케이프해서 | `s` |
| 포인터 | `p` 16진수 주소 | `p` |

- 대문자 타입 글자: 출력에 들어가는 글자도 대문자가 됨. `x` → `2a`, `X` → `2A`
- 포인터는 `void*`만 형식화할 수 있음. 다른 포인터는 `static_cast<void*>(포인터)`로 바꾼 뒤 넘김
- `?` (이스케이프): 다음 글에서 다룸

### 대체 형식

- `#`를 붙였을 때 달라지는 것

| 값의 타입 | `#`의 효과 | 예 |
| --- | --- | --- |
| 정수 | 진법 접두어를 붙임 | `{:#b}` → `0b101010`, `{:#o}` → `052`, `{:#x}` → `0x2a`, `{:#X}` → `0X2A` |
| 부동소수점 | 소수점 아래 숫자가 없어도 소수점을 항상 출력 | `{:#.0f}`에 3.0 → `3.` |

## 정밀도와 0 채움

### 정밀도

- **정밀도** (precision): 점(`.`) 뒤에 적는 숫자. 부동소수점과 문자열에만 쓸 수 있음

| 값의 타입 | 타입 글자 | 정밀도의 뜻 |
| --- | --- | --- |
| 부동소수점 | `f`, `e` | 소수점 **아래** 자릿수 |
| 부동소수점 | `g` 또는 생략 | 소수점 앞뒤를 합친 **유효 숫자** 개수 |
| 문자열 | | 앞에서부터 출력할 글자 수 |

- `f`, `e`, `g`에 정밀도를 적지 않으면 6
- 타입 글자도 정밀도도 적지 않으면: 그 값을 정확히 되살릴 수 있는 가장 짧은 표현. 앞 글의 `std::to_chars`와 같은 방식
- **동적 정밀도**: 정밀도 자리에도 `{}`를 쓸 수 있음. `{:{}.{}f}` → 값, 너비, 정밀도 순서로 인수를 받음

### 0 채움

- 너비 앞에 `0`을 적으면 남는 칸을 숫자 **앞의 0**으로 채움
  - 0은 부호와 진법 접두어 **뒤에** 들어감. `{:+06d}` → `+00042`, `{:#06x}` → `0x002a`
- 정렬 기호를 함께 적으면 `0`은 무시됨
- 채움 문자로 `0`을 쓰는 것(`{:0>6}`)과의 차이: 채움 문자 방식은 부호 앞에 0이 옴. 음수에서 `000-42`처럼 됨

- 볼 것
  - 첫 줄: 타입을 적지 않은 `double`. 자릿수가 길게 나옴
  - `{:.2f}`와 `{:.3}`가 둘 다 `1.37`: 앞의 것은 소수점 아래 2자리, 뒤의 것은 유효 숫자 3자리

## 로케일

- **로케일** (locale): 나라와 언어에 따라 달라지는 표기 규칙의 묶음. 숫자의 자릿수 구분 기호, 소수점 기호 등 <CppRef path="cpp/locale/locale" />
- `L`: 로케일에 맞춘 형식으로 출력. 정수, 부동소수점, `bool`에 쓸 수 있음

| 값의 타입 | `L`의 효과 |
| --- | --- |
| 정수 | 그 로케일의 자릿수 구분 기호를 넣음 |
| 부동소수점 | 그 로케일의 자릿수 구분 기호와 소수점 기호를 씀 |
| `bool` (글자로 출력할 때) | 그 로케일의 "참", "거짓" 표현을 씀 |

- 쓰는 법: `std::format`의 첫 인수로 `std::locale` 객체를 넘김
  - `std::format(std::locale{ "de_DE.UTF-8" }, "{:L}", 1234.5)`
  - 로케일을 넘기는 형태는 `std::format`에만 있음. `std::print` / `std::println`에는 없음
- 로케일 이름은 운영체제마다 다르고, 그 로케일이 설치되어 있어야 함. 없으면 예외가 던져짐
- 로케일의 자세한 내용: 21장에서 다룸

## 이전 표준에서는

- 형식 지정자는 `std::format`과 함께 C++20에서 들어옴
- 그 이전: I/O 스트림의 조작자 <CppRef path="cpp/io/manip" />. `<iomanip>` 헤더

| 형식 지정자 | 조작자 |
| --- | --- |
| `{:7}` | `std::setw(7)` |
| `{:<7}`, `{:>7}` | `std::left`, `std::right` |
| `{:_>7}` | `std::setfill('_')` |
| `{:+}` | `std::showpos` |
| `{:x}`, `{:o}` | `std::hex`, `std::oct` |
| `{:#x}` | `std::showbase` |
| `{:.2f}` | `std::fixed`, `std::setprecision(2)` |
| `{:e}` | `std::scientific` |

## 헷갈리기 쉬운 점

- 순서를 바꿔 적으면 안 됨
  - `{:.2+f}`: 컴파일 오류. 부호는 정밀도보다 앞에 적음: `{:+.2f}`
  - `{:8>}`: 컴파일은 되지만 뜻이 다름. `8`이 채움 문자로 읽히고 너비는 없는 것이 되어 아무 효과가 없음. 너비 8에 오른쪽 정렬은 `{:>8}`
- 너비는 최소일 뿐
  - `{:3}`에 123456을 넣으면 여섯 자리가 모두 나옴. 자르지 않음
  - 문자열을 자르려면 정밀도: `{:.3}`
- `{:.2}`와 `{:.2f}`는 다름
  - `{:.2}`: 유효 숫자 2자리. 1234.5 → `1.2e+03`
  - `{:.2f}`: 소수점 아래 2자리. 1234.5 → `1234.50`
- 정수에는 정밀도를 쓸 수 없음
  - `{:.2}`에 `int`를 넣으면 컴파일 오류. 소수점 아래를 보이려면 `double`로 바꾼 뒤 `{:.2f}`

## 정리

| 형식 지정자 | 뜻 | 예 (값 42) |
| --- | --- | --- |
| `{:7}` | 너비 7 | 공백 5칸 뒤에 `42` |
| `{:<7}` / `{:>7}` / `{:^7}` | 왼쪽 / 오른쪽 / 가운데 정렬 | |
| `{:*^7}` | 채움 문자 `*` | `**42***` |
| `{:+}` | 양수에도 부호 | `+42` |
| `{:b}` / `{:x}` / `{:#x}` | 2진수 / 16진수 / 접두어 붙인 16진수 | `101010` / `2a` / `0x2a` |
| `{:06}` | 0으로 채움 | `000042` |
| `{:.2f}` | 소수점 아래 2자리 (부동소수점) | |
| `{:.3}` | 유효 숫자 3자리 또는 문자열 앞 3글자 | |
| `{:{}}` | 너비를 인수로 받음 | |
| `{:L}` | 로케일에 맞춘 형식 | |
