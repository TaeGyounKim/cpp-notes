- 다루는 것: "이것은 바뀌지 않는다"를 코드에 적는 방법
- 배우는 요소: `const` 변수, 포인터와 `const`, `const` 매개변수, `const` 멤버 함수
- `const`의 쓰임은 여러 가지지만 뜻은 하나. 붙은 대상을 바꾸지 못하게 함

## const가 하는 일

- `const`: constant(상수)의 줄임. 붙은 대상이 바뀌지 않는다고 선언하는 키워드 <CppRef path="cpp/language/cv" />
- 컴파일러가 약속을 지키게 함. 바꾸려는 코드는 컴파일 오류
- 얻는 것
  - 실수로 값을 바꾸는 버그를 컴파일 단계에서 잡음
  - 코드를 읽는 사람이 "이 값은 바뀌지 않는다"는 것을 바로 알 수 있음
  - 컴파일러가 더 나은 최적화를 할 수 있음

## 상수 만들기

- 변수 선언 앞에 `const`를 붙이면 그 값은 바꿀 수 없음
- 반드시 선언과 함께 초기화해야 함. 나중에 값을 넣을 수 없기 때문

```cpp
const int versionMajor{ 2 };
const double pi{ 3.141592653589793 };
```

- 어떤 변수에나 붙일 수 있음: 지역 변수, 전역 변수, 클래스의 데이터 멤버
- C 언어의 방식: 전처리기의 `#define`으로 이름을 붙임 (`#define VERSION 2`)
  - C++에서는 `#define` 대신 `const`를 쓸 것
  - 이유: `const` 변수는 타입이 있고, 범위 규칙을 따르고, 디버거에서도 이름이 보임. `#define`은 컴파일 전에 글자를 바꿔치기할 뿐
  - `#define`: 11장에서 다룸

## 포인터와 const

- 포인터에는 바꿀 수 있는 것이 두 가지 있음
  - 포인터가 **가리키는 값**
  - **포인터 자신**, 즉 어디를 가리키는지
- `const`를 어디에 두느냐에 따라 무엇을 막을지가 달라짐

| 선언 | 가리키는 값 바꾸기 (`*p = 1;`) | 가리키는 곳 바꾸기 (`p = &other;`) |
| --- | --- | --- |
| `int* p` | 가능 | 가능 |
| `const int* p` | **불가** | 가능 |
| `int* const p` | 가능 | **불가** |
| `const int* const p` | **불가** | **불가** |

- `const int* p`와 `int const* p`는 같은 뜻. 앞의 것을 훨씬 많이 씀
- 포인터 자신이 `const`이면 선언할 때 반드시 초기화해야 함. 나중에 가리킬 곳을 정할 수 없기 때문

### 읽는 법

- 규칙 하나: `const`는 **바로 왼쪽**에 있는 것에 적용됨
  - `int const* const p`: 첫 `const`의 왼쪽은 `int` → 가리키는 `int`가 상수. 둘째 `const`의 왼쪽은 `*` → 포인터가 상수
  - 예외: 맨 앞에 온 `const`는 왼쪽에 아무것도 없으므로 바로 오른쪽에 적용됨. `const int*`의 `const`는 `int`에 적용
- 더 쉬운 방법: **오른쪽에서 왼쪽으로** 읽음

| 선언 | 오른쪽부터 읽으면 |
| --- | --- |
| `int* const p` | `p`는 상수인 포인터, `int`를 가리킴 |
| `const int* p` | `p`는 포인터, 상수인 `int`를 가리킴 |
| `const int* const p` | `p`는 상수인 포인터, 상수인 `int`를 가리킴 |

## 매개변수를 보호하는 const

- 문제 상황
  - 함수에 포인터를 넘기면 함수가 원본을 바꿀 수 있음
  - 호출하는 쪽은 "이 함수가 내 데이터를 바꾸는가?"를 함수 본문을 읽어 봐야 알 수 있음
- `const`를 붙인 매개변수: "받은 것을 바꾸지 않겠다"는 약속을 함수 선언에 적는 것

```cpp
void printTitle(const std::string* title);
```

- 함수 안에서 `*title`을 바꾸려고 하면 컴파일 오류
- 호출하는 쪽은 준비할 것이 없음. `const`가 아닌 것은 `const`인 것으로 자동 변환됨
  - `std::string*` → `const std::string*`: 자동
  - 반대 방향은 자동으로 되지 않음. 제한을 푸는 방향이기 때문
- 값으로 받는 매개변수에도 붙일 수 있음: `int doubled(const int value)`
  - 어차피 복사본이므로 호출한 쪽에는 영향이 없음
  - 함수 안에서 실수로 매개변수를 바꾸는 것을 막는 용도
- `const`가 막는 것은 **실수**. 일부러 제한을 푸는 방법도 있음(`const_cast`). 다음 글에서 다룸

## const 멤버 함수

- **const 멤버 함수** (const member function): 객체의 데이터 멤버를 바꾸지 않겠다고 약속한 멤버 함수 <CppRef path="cpp/language/member_functions" />
- 적는 법: 매개변수 괄호 **뒤**에 `const`를 붙임

```cpp
class MovieTicket
{
public:
    int getSeatCount() const;             // 읽기만 함
    void setSeatCount(int seatCount);     // 바꿈
};
```

- 선언과 정의를 따로 적을 때는 양쪽 모두에 `const`를 붙여야 함

```cpp
int MovieTicket::getSeatCount() const
{
    return m_seatCount;
}
```

- `const` 멤버 함수 안에서 데이터 멤버를 바꾸면 컴파일 오류
- `const` 객체로는 `const` 멤버 함수만 부를 수 있음
  - `const` 포인터나 `const` 참조를 거쳐 객체를 쓸 때도 마찬가지
  - 그래서 읽기만 하는 함수에 `const`를 빠뜨리면, 나중에 그 객체를 `const`로 받는 코드에서 그 함수를 못 부르게 됨
- **const 정확성** (const-correctness): 바뀌지 않는 것에는 빠짐없이 `const`를 붙이는 원칙
  - 데이터 멤버를 바꾸지 않는 멤버 함수는 모두 `const`로 선언할 것
- 부르는 이름
  - 조회자 (inspector): `const` 멤버 함수. 값을 읽기만 함
  - 변경자 (mutator): `const`가 아닌 멤버 함수. 값을 바꿈

## 헷갈리기 쉬운 점

- `const int* p`는 "값이 절대 바뀌지 않는다"는 뜻이 아님
  - "`p`를 거쳐서는 바꿀 수 없다"는 뜻. 원래 변수가 `const`가 아니면 그 변수로는 바꿀 수 있음
  - `int value{ 1 }; const int* p{ &value }; value = 2;` → 가능. `*p`로 읽으면 2
- `const`의 위치가 헷갈릴 때: 오른쪽에서 왼쪽으로 읽을 것
- 멤버 함수의 `const`는 괄호 뒤
  - `const int getCount();`: 반환 타입이 `const int`라는 뜻. 멤버 함수가 `const`인 것이 아님
  - `int getCount() const;`: 멤버 함수가 `const`

## 정리

| 요소 | 핵심 |
| --- | --- |
| `const 타입 이름{ 값 };` | 바꿀 수 없는 변수. 선언과 함께 초기화 |
| `const int* p` | 가리키는 값을 바꿀 수 없음 |
| `int* const p` | 가리키는 곳을 바꿀 수 없음 |
| `const int* const p` | 둘 다 바꿀 수 없음 |
| `const` 매개변수 | 받은 것을 바꾸지 않겠다는 약속 |
| `const` 멤버 함수 | 괄호 뒤에 `const`. 데이터 멤버를 바꾸지 않음 |
| const 정확성 | 바뀌지 않는 것에는 빠짐없이 `const` |

## 복습 질문

<details>
<summary>`int* const p{ &value };`에서 바꿀 수 없는 것은 무엇인가요?</summary>

- 포인터 `p` 자신. 다른 곳을 가리키게 할 수 없음
- `p`가 가리키는 `value`의 값은 `*p`로 바꿀 수 있음

</details>

<details>
<summary>`const int* p`와 `int const* p`는 무엇이 다른가요?</summary>

- 같음. 둘 다 "가리키는 `int`를 바꿀 수 없는 포인터"
- `const`가 `int`의 앞에 오든 뒤에 오든 뜻이 같음

</details>

<details>
<summary>함수가 `void show(const std::string* text)`로 선언되어 있으면 호출하는 쪽은 무엇을 알 수 있나요?</summary>

- 이 함수는 넘긴 문자열을 바꾸지 않음
- 함수 본문을 읽지 않아도 선언만 보고 알 수 있음

</details>

<details>
<summary>`int getCount() const;`의 `const`는 무엇을 뜻하나요?</summary>

- 이 멤버 함수가 객체의 데이터 멤버를 바꾸지 않는다는 뜻
- `const` 객체로도 부를 수 있음

</details>

<details>
<summary>`const` 객체로 `setSeatCount(3)`을 부르면 어떻게 되나요?</summary>

- 컴파일 오류
- `const` 객체로는 `const` 멤버 함수만 부를 수 있음

</details>
