## 리터럴

- **리터럴** (literal): 코드에 직접 적은 값. `123`, `3.14`, `'a'`, `"안녕"` 같은 것 <CppRef path="cpp/language/expressions#Literals" />

### 정수 리터럴

- 같은 수를 네 가지 진법으로 적을 수 있음 <CppRef path="cpp/language/integer_literal" />

| 진법 | 123을 적는 법 | 표시 | 들어온 표준 |
| --- | --- | --- | --- |
| 10진수 | `123` | 없음 | |
| 8진수 | `0173` | `0`으로 시작 | |
| 16진수 | `0x7B` | `0x`로 시작 | |
| 2진수 | `0b1111011` | `0b`로 시작 | <Badge text="C++14" /> |

- 주의: 숫자 앞에 `0`을 붙이지 말 것
  - `010`은 십이 아니라 8진수 10, 즉 8
  - 자릿수를 맞추려고 무심코 `0`을 붙이면 다른 수가 됨

### 그 밖의 리터럴

| 종류 | 예 | 타입 |
| --- | --- | --- |
| 부동소수점 <CppRef path="cpp/language/floating_literal" /> | `3.14` | `double` |
| 부동소수점 + 접미사 `f` | `3.14f` | `float` |
| 16진 부동소수점 <Badge text="C++17" /> | `0x3.ABCp-10` | `double` |
| 문자 | `'a'` | `char` |
| 문자열 | `"character array"` | 끝에 0이 붙은 문자 배열 |

- **접미사** (suffix): 리터럴 뒤에 붙여 타입을 지정하는 글자
  - `3.14`는 `double`, `3.14f`는 `float`
- **자릿수 구분자** (digit separator): 숫자 사이에 넣는 작은따옴표 <Badge text="C++14" />
  - `23'456'789`, `0.123'456f`
  - 읽기 편하라고 넣는 것. 값에는 영향이 없고 어디에 넣어도 됨
- 문자열 리터럴 이어 쓰기: 공백만 사이에 두고 나란히 쓴 문자열 리터럴은 하나로 합쳐짐
  - 긴 문자열을 여러 줄에 나눠 쓸 때 사용
- 리터럴의 종류를 직접 만드는 방법(사용자 정의 리터럴): 15장에서 다룸 <Badge text="C++11" /> <CppRef path="cpp/language/user_literal" />

- 해 볼 것: `main` 안에 `std::println("{}", 010);`을 추가하고 실행
  - 결과: `8` 출력. 앞에 붙은 `0` 때문에 8진수로 읽힘
- 세 번째 줄 출력에서 볼 것: 같은 3분의 1인데 `float`는 8자리쯤, `double`은 16자리쯤에서 끊김

## 변수

- **변수** (variable): 값을 담아 두는, 이름이 붙은 칸
- 선언 위치: 코드의 거의 어디에서나 선언할 수 있음
- 쓸 수 있는 범위: 선언한 줄의 아래부터, 그 변수가 속한 블록(`{ }`)이 끝날 때까지

### 초기화

- **초기화** (initialization): 변수를 만들면서 첫 값을 넣는 것 <CppRef path="cpp/language/initialization" />
- 방법 두 가지

| 문법 | 이름 | 들어온 표준 |
| --- | --- | --- |
| `int total{ 7 };` | **유니폼 초기화** (uniform initialization, 중괄호 초기화) <CppRef path="cpp/language/list_initialization" /> | <Badge text="C++11" /> |
| `int total = 7;` | 대입 문법 | |

- 권장: 유니폼 초기화. 이 사이트의 예제도 이 문법을 씀
  - 권장하는 이유: 이 장의 뒤쪽 "클래스 첫걸음과 유니폼 초기화" 글에서 다룸
- **초기화하지 않은 변수** (uninitialized variable): `int count;`처럼 값을 넣지 않고 만든 변수 <CppRef path="cpp/language/default_initialization" />
  - 그 자리의 메모리에 원래 있던 값이 그대로 들어 있음. 무슨 값일지 알 수 없음
  - 수많은 버그의 원인. 변수는 항상 초기화할 것

- 아래 코드는 초기화하지 않은 변수를 실제로 읽어 봄

- `count`의 출력은 실행 환경에 따라 달라짐
  - 0이 나오더라도 우연일 뿐, 0이 보장된 것이 아님
- 컴파일러가 경고해 주는 경우도 있지만 항상은 아님. 이 코드는 경고 없이 컴파일됨
- 해 볼 것: `int count;`를 `int count{};`로 바꿔 실행. 항상 `0`이 출력됨

### 0으로 초기화하기

- 방법 두 가지: `{0}`을 쓰거나, 빈 중괄호 `{}`를 씀
- **영 초기화** (zero initialization): 빈 중괄호 `{}`로 하는 초기화. 타입에 맞는 "0에 해당하는 값"이 들어감 <CppRef path="cpp/language/zero_initialization" />

| 타입 | `{}`로 초기화한 값 |
| --- | --- |
| 정수 (`int`, `char` 등) | `0` |
| 부동소수점 (`float`, `double`) | `0.0` |
| `bool` | `false` |
| 포인터 | `nullptr` |
| 객체 | 기본 생성자로 만들어짐 (뒤에서 다룸) |

## 기본 타입

- C++의 변수는 반드시 타입이 정해져 있음 (강타입, strongly typed)
- 자주 쓰는 기본 타입 <CppRef path="cpp/language/types" />

| 타입 | 담는 값 | 보통의 크기 | 예 |
| --- | --- | --- | --- |
| `int` | 정수 | 4바이트 | `int i{ -7 };` |
| `short` | 작은 정수 | 2바이트 | `short s{ 13 };` |
| `long` | 큰 정수 | 4바이트 또는 8바이트 | `long l{ -7L };` |
| `long long` <Badge text="C++11" /> | 더 큰 정수 | 8바이트 | `long long ll{ 14LL };` |
| `unsigned int` 등 | 0 이상의 정수만 | 원래 타입과 같음 | `unsigned int u{ 2U };` |
| `float` | 부동소수점 (floating-point, 단정밀도) | 4바이트 | `float f{ 7.2f };` |
| `double` | 부동소수점 (배정밀도) | 8바이트 | `double d{ 7.2 };` |
| `long double` | 부동소수점 (확장 정밀도) | 8바이트 이상 | `long double d{ 16.98L };` |
| `char` | 문자 하나 | 1바이트 | `char ch{ 'm' };` |
| `char8_t` <Badge text="C++20" /> | UTF-8 문자 하나 | 1바이트 | `char8_t c8{ u8'm' };` |
| `char16_t` <Badge text="C++11" /> | UTF-16 문자 하나 | 2바이트 | `char16_t c16{ u'm' };` |
| `char32_t` <Badge text="C++11" /> | UTF-32 문자 하나 | 4바이트 | `char32_t c32{ U'm' };` |
| `wchar_t` | 넓은 문자 하나 | 컴파일러마다 다름 | `wchar_t w{ L'm' };` |
| `bool` | 참 또는 거짓 | 1바이트 | `bool b{ true };` |

- 크기는 표준이 정확히 정하지 않음. 표의 값은 흔한 환경의 값
  - `long`: Windows에서는 4바이트, 64비트 Linux에서는 8바이트
- 같은 타입의 여러 표기
  - `short`, `short int`, `signed short`, `signed short int`는 모두 같은 타입
  - `unsigned`만 쓰면 `unsigned int`
- 리터럴 접미사: `L`은 `long`, `LL`은 `long long`, `U`는 `unsigned`, 함께 쓰면 `UL`, `ULL`

### 정수 타입의 범위

| 크기 | 부호 있음 (signed) | 부호 없음 (unsigned) |
| --- | --- | --- |
| 1바이트 (`char`) | -128 ~ 127 | 0 ~ 255 |
| 2바이트 | -32,768 ~ 32,767 | 0 ~ 65,535 |
| 4바이트 | -2,147,483,648 ~ 2,147,483,647 | 0 ~ 4,294,967,295 |
| 8바이트 | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 | 0 ~ 18,446,744,073,709,551,615 |

### char에 대해 알아 둘 것

- `char`, `signed char`, `unsigned char`는 서로 다른 세 타입
- `char`가 부호 있는 타입인지 없는 타입인지는 컴파일러마다 다름 → 그 점에 기대는 코드는 금물
- `char`는 문자를 나타낼 때만 쓸 것
- 바이트 하나를 나타낼 때: `std::byte` 사용 <Badge text="C++17" /> <CppRef path="cpp/types/byte" />
  - `<cstddef>` 헤더에 있음. `std::byte b{ 42 };`
  - 장점: "문자가 아니라 메모리의 바이트 하나"라는 의도가 드러남
  - C++11 ~ C++14: `std::byte`가 없음. `unsigned char`를 대신 씀

### 문자열 타입은 어디에

- 기본 타입에는 문자열 타입이 없음
- 표준 라이브러리가 `std::string`을 제공함. 이 장의 뒤쪽과 2장에서 다룸

## 타입별 한계값

- 어떤 타입이 담을 수 있는 가장 큰 값, 가장 작은 값을 알아내는 표준 방법: `std::numeric_limits` <Badge text="C++11" /> <CppRef path="cpp/types/numeric_limits" />
- `<limits>` 헤더에 있음
- 쓰는 법: 꺾쇠괄호 안에 알고 싶은 타입을 적음. `std::numeric_limits<int>::max()`
  - 꺾쇠괄호를 쓰는 이유(클래스 템플릿): 12장에서 다룸. 지금은 쓰는 법만 알면 충분
- C 언어의 `INT_MAX` 같은 상수도 쓸 수는 있지만 `std::numeric_limits`를 권장

<RunCode client:load code={limitsCode} />

- `min()`과 `lowest()`의 차이

| | 정수 타입 | 부동소수점 타입 |
| --- | --- | --- |
| `max()` | 가장 큰 값 | 가장 큰 값 |
| `min()` | 가장 작은 값 (음수) | 나타낼 수 있는 **가장 작은 양수** |
| `lowest()` | `min()`과 같음 | 가장 작은 값 (음수). `-max()`와 같음 |

- 해 볼 것: 코드의 `int`를 모두 `short`, `unsigned int`, `long long`으로 차례로 바꿔 가며 실행

### 이전 표준에서는

- C++11: 유니폼 초기화, 영 초기화, `long long`, `std::numeric_limits`의 `lowest()` 모두 사용 가능
- 달라지는 것은 출력 방법뿐 (`std::println` 대신 `std::cout`)

## 복습 질문

<details>
<summary>`int x{ 010 };`에서 `x`의 값은 얼마인가요?</summary>

- 8
- `0`으로 시작하는 정수 리터럴은 8진수로 읽힘

</details>

<details>
<summary>`int count;`와 `int count{};`는 무엇이 다른가요?</summary>

- `int count;`: 초기화하지 않음. 값을 알 수 없음
- `int count{};`: 영 초기화. 값은 0

</details>

<details>
<summary>`3.14`와 `3.14f`는 무엇이 다른가요?</summary>

- `3.14`: `double`
- `3.14f`: 접미사 `f`가 붙어 `float`

</details>

<details>
<summary>`std::numeric_limits<double>::min()`은 가장 작은 음수인가요?</summary>

- 아님. 나타낼 수 있는 가장 작은 양수
- 가장 작은 값(음수)은 `lowest()`

</details>

<details>
<summary>C++11까지만 쓸 수 있는 프로젝트에서 `int mask{ 0b1111'0000 };`를 어떻게 바꿔 쓰나요?</summary>

- `int mask{ 0xF0 };`
- 2진수 리터럴과 자릿수 구분자는 둘 다 C++14부터 쓸 수 있음
- 중괄호 초기화는 C++11에서도 쓸 수 있으므로 그대로 둠

</details>
