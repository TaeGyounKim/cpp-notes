C++23을 기준으로 쓴 교재나 예제 코드는 대부분 이렇게 시작합니다.

```cpp
import std;
```

이 사이트의 실행 예제는 이렇게 시작합니다.

```cpp
#include <print>
```

둘은 방법이 다를 뿐 결과는 같습니다.

## 무엇이 다른가

C++ 표준 라이브러리의 기능을 쓰려면 먼저 그 기능을 내 코드로 가져와야 합니다. 가져오는 방법은 두 가지입니다.

| | `import std;` | `#include <헤더>` |
| --- | --- | --- |
| 방식 | 표준 라이브러리 전체를 한 번에 가져옴 | 필요한 헤더 파일을 하나씩 가져옴 |
| 도입 시기 | C++23 | C++ 초창기부터 |
| 장점 | 어떤 헤더가 필요한지 몰라도 됨, 큰 프로젝트에서 컴파일이 빠름 | 모든 컴파일러와 도구에서 동작 |

`import std;`로 쓸 수 있는 기능은 전부 `#include`로도 쓸 수 있습니다. `import std;`가 있어야만 되는 기능은 없습니다.

## 이 사이트가 #include를 쓰는 이유

이 사이트의 코드는 Compiler Explorer 서버에서 실행되는데, 이 서버에서는 `import std;`가 동작하지 않습니다.
그래서 실행 예제는 필요한 헤더를 `#include`로 가져옵니다.

<RunCode client:load code={helloCode} />

`import std;`로 시작하는 다른 곳의 예제를 이 사이트에서 실행해 보고 싶다면 그 줄을 지우고, 아래 표를 보고 필요한 헤더를 `#include`로 넣으면 됩니다.

## 자주 쓰는 헤더

| 쓰려는 것 | 헤더 |
| --- | --- |
| `std::println`, `std::print` | `<print>` |
| `std::format` | `<format>` |
| `std::cout`, `std::cin`, `std::cerr` | `<iostream>` |
| `std::string` | `<string>` |
| `std::vector` | `<vector>` |
| `std::array` | `<array>` |
| `std::optional` | `<optional>` |
| `std::pair` | `<utility>` |

새로운 기능이 나올 때마다 글에서 어느 헤더에 들어 있는지 함께 적습니다.

:::tip[내 컴퓨터에서는 import std를 써도 됩니다]
최신 Visual Studio처럼 `import std;`를 지원하는 환경에서 직접 실습한다면 `import std;`를 그대로 써도 됩니다.
:::
