- 다루는 것: 객체를 배열처럼 `obj[i]`로 쓰게 하는 **첨자 연산자** (subscript operator) `operator[]`
- 이 글에서 배우는 요소: 참조를 돌려주는 `operator[]`, `const` 판, 강한 보장을 지키는 크기 조정, 다차원 첨자 <Badge text="C++23" />, 정수가 아닌 첨자, `static operator[]` <Badge text="C++23" />

## 자라는 배열

- 표준 라이브러리의 `std::vector`나 `std::array`를 모른다고 치고, 동적으로 할당하는 배열 클래스를 직접 만든다고 하자
  - 정해진 위치의 원소를 읽고 쓸 수 있음
  - 메모리 할당은 뒤에서 알아서 함
- 처음 떠올릴 만한 인터페이스: `getElementAt(i)`(범위 밖이면 예외)와 `setElementAt(i, value)`(범위 밖이면 공간을 늘림)
  - 쓰는 쪽은 메모리를 신경 쓰지 않고 1번, 100번, 1000번 원소를 정할 수 있음
- 공간을 늘리는 `resize()`는 **예외에 안전하게** 구현함

```cpp
template <typename T>
void GrowArray<T>::resize(std::size_t newSize)
{
    auto bigger{ std::make_unique<T[]>(newSize) };   // 새 배열(영 초기화)
    for (std::size_t i{ 0 }; i < m_size; ++i) {
        bigger[i] = m_data[i];                        // 원소 복사
    }
    m_data = std::move(bigger);   // 모두 성공한 뒤에야 바꿈
    m_size = newSize;
}
```

- 새 배열을 `std::unique_ptr`로 잡고 원소를 복사함. 복사 도중 예외가 나면 `unique_ptr`가 새 배열을 알아서 해제함
- 할당과 복사가 모두 성공한 뒤에만 옛 배열을 새 배열로 바꿈. 그래서 실패해도 객체는 예전 그대로(강한 보장, 14장)
  - 날 포인터 `m_elements`를 쓴다면 마지막에 `delete[]`로 옛 배열을 지우고 `bigger.release()`로 소유권을 넘겨받음
- 원소를 복사하는 대신, 원소 타입의 이동 대입이 `noexcept`일 때만 이동하게 해도 강한 보장이 유지됨(26장)

:::note
이 구현은 메모리를 아끼지 않는다. 배열을 만들고 4000번 원소만 정해도 4004개 원소의 메모리를 잡고, 4000번 말고는 모두 영으로 초기화한다.
:::

## operator[]

- `getElementAt()`, `setElementAt()`을 매번 쓰기는 불편함. 첨자 연산자를 더함 <CppRef path="cpp/language/operators" />

```cpp
template <typename T>
T& GrowArray<T>::operator[](std::size_t i)
{
    if (i >= m_size) { resize(i + Extra); }   // 필요한 위치보다 조금 더
    return m_data[i];
}
```

```cpp
GrowArray<int> a;
for (std::size_t i{ 0 }; i < 10; i += 3) { a[i] = 100; }   // 쓰기
std::println("{}", a[3]);                                   // 읽기
```

- `operator[]`가 원소의 **참조**를 돌려주므로 읽기와 쓰기 모두에 씀
  - 대입의 왼쪽에 쓰면 그 참조를 통해 배열 안의 원소가 실제로 바뀜

## 읽기 전용 접근

- 원소를 좌측값으로 돌려주는 것이 편할 때도 있지만, 늘 그러고 싶지는 않음. `const` 참조를 돌려주는 읽기 전용 접근도 제공하면 좋음
- 두 판을 둠

```cpp
T& operator[](std::size_t i);
const T& operator[](std::size_t i) const;
```

- 반환 타입만으로는 오버로드할 수 없으므로, 둘째 판은 `const` 참조를 돌려주면서 멤버 함수 자체도 `const`로 표시함
- `const` 판은 범위 밖이면 공간을 늘리지 않고 예외를 던짐. 값을 읽기만 하는데 공간을 늘릴 이유가 없음

```cpp
template <typename T>
const T& GrowArray<T>::operator[](std::size_t i) const
{
    if (i >= m_size) { throw std::out_of_range{ "범위 밖" }; }
    return m_data[i];
}

void show(const GrowArray<int>& a)
{
    for (std::size_t i{ 0 }; i < a.size(); ++i) {
        std::print("{} ", a[i]);   // a가 const라서 const 판이 불림
    }
}
```

- `show()` 안에서 `const` 판이 불리는 것은 매개변수 `a`가 `const`이기 때문. `const`가 아니었다면 결과를 고치지 않아도 `const`가 아닌 판이 불림
- 예외 대신 영 초기화된 원소를 돌려주는 방법도 있음. 어느 쪽이 맞는지는 쓰임새에 따라 정함

```cpp
if (i >= m_size) {
    static T nullValue{ T{} };   // 영 초기화
    return nullValue;
}
```

:::note
**영 초기화** (zero initialization)는 클래스 객체를 기본 생성자로 만들고, `char`, `int` 같은 정수 타입은 0, 부동소수점 타입은 0.0, 포인터 타입은 `nullptr`로 초기화한다.
:::

## 다차원 첨자 연산자

- <Badge text="C++23" /> 첨자 연산자가 **인덱스를 여러 개** 받을 수 있음. 차원 수만큼 매개변수를 둠
- 예: 12장 `Table`의 `at(row, col)`을 2차원 첨자 연산자로 바꿈

```cpp
template <typename T>
class Table
{
public:
    std::optional<T>& operator[](std::size_t row, std::size_t col);
    const std::optional<T>& operator[](std::size_t row, std::size_t col) const;
    // 나머지 생략
};

template <typename T>
std::optional<T>& Table<T>::operator[](std::size_t row, std::size_t col)
{
    return const_cast<std::optional<T>&>(std::as_const(*this)[row, col]);
}
```

- 쓸 때: `table[1, 2] = 7;`
- C++23 이전의 `t[1, 2]`는 쉼표 연산자로 `t[2]`가 되었음(C++20에서 권장하지 않게 됨). 그래서 이전 표준에서는 `operator()(row, col)`이나 행을 돌려주는 `operator[]`를 이어 쓰는 `t[r][c]` 방식을 썼음

## 정수가 아닌 첨자

- "인덱싱"은 컬렉션에 어떤 **키**를 주는 것으로 자연스럽게 넓힐 수 있음. 벡터 같은 선형 배열은 키가 위치일 뿐인 특수한 경우
- `operator[]`의 인수는 키의 영역과 값의 영역을 잇는 것이라 생각하면 됨. 그래서 **어떤 타입이든** 첨자로 쓸 수 있고 정수일 필요가 없음
  - 표준 라이브러리의 연관 컨테이너 `std::map` 등이 그렇게 함(18장)
  - 예: 문자열 키로 값을 찾는 연관 배열이라면 `operator[]`가 `std::string_view`를 받음

## static 첨자 연산자

- <Badge text="C++23" /> 구현에 `this`가 필요 없다면(`static`이 아닌 데이터 멤버나 멤버 함수를 쓰지 않으면) 첨자 연산자를 `static`으로 표시할 수 있음
  - 컴파일러가 `this` 포인터를 신경 쓰지 않아도 되어 더 잘 최적화할 수 있음

```cpp
enum class Level { Low, Mid, High };

struct LevelName
{
    static constexpr std::string_view operator[](Level level) noexcept
    {
        switch (level) {
        case Level::Low: return "낮음";
        case Level::Mid: return "보통";
        case Level::High: return "높음";
        }
        return "?";
    }
};

std::println("{}", LevelName{}[Level::High]);   // 높음
```

- 열거형을 첨자로 쓰는 예이기도 함. `constexpr`(9장), `noexcept`(14장)도 함께 붙일 수 있음

## 이전 표준에서는

| 이 글에서 쓴 것 | 들어온 표준 | 그 이전에는 |
| --- | --- | --- |
| 다차원 `operator[]` | C++23 | `operator()(r, c)`, 또는 행을 돌려주는 `operator[]`로 `b[r][c]` |
| `static operator[]` | C++23 | 보통 멤버 `operator[]` |
| `std::make_unique<T[]>` | C++14 | `std::unique_ptr<T[]>(new T[n]())` |

## 헷갈리기 쉬운 점

- `operator[]`는 값을 돌려줘도 된다?
  - 값이면 `a[i] = 5`가 기본 타입에서는 컴파일 오류, 클래스 타입에서는 임시 복사본에 대입되어 배열은 그대로. 참조를 돌려줌
- `const` 판은 반환 타입만 다르게 하면 된다?
  - 반환 타입만으로는 오버로드할 수 없음. 멤버 함수에 `const`를 붙여야 함
- 고치지 않으면 `const` 판이 불린다?
  - 객체(또는 참조)가 `const`일 때만 `const` 판이 불림
- C++20에서 `t[1, 2]`는 2차원 첨자다?
  - C++23부터. 그 전에는 쉼표 연산자로 `t[2]`
- 첨자는 정수여야 한다?
  - 어떤 타입이든 됨(`std::map`의 키처럼)

## 정리

| 요소 | 핵심 |
| --- | --- |
| `T& operator[](std::size_t)` | 읽고 쓰기. 참조를 돌려줌 |
| `const T& operator[](std::size_t) const` | `const` 객체의 읽기 전용 접근 |
| 크기 조정 | 새 배열에 다 옮긴 뒤 바꿈(강한 보장) |
| 다차원 첨자 | `operator[](r, c)`(C++23) |
| 정수가 아닌 첨자 | 키 타입 아무거나. `std::map`처럼 |
| `static operator[]` | `this`가 필요 없을 때(C++23) |

<summary>`int operator[](std::size_t i)`처럼 값을 돌려주면 `a[2] = 9;`는 어떻게 되는가?</summary>

- 대개 컴파일 오류. 기본 타입의 임시 값(우측값)에는 대입할 수 없음. 클래스 타입이었다면 컴파일은 되더라도 임시 복사본에 대입될 뿐 배열은 바뀌지 않음

</details>

<summary>C++20 이하에서 `m[r][c]` 모양을 지원하려면 첫 `operator[]`가 무엇을 돌려줘야 하는가?</summary>
