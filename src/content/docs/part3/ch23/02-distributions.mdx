- 다루는 것: 엔진이 만든 난수를 원하는 범위와 모양으로 바꾸는 분포
- 이 글에서 배우는 요소: 분포 계열 다섯, `uniform_int_distribution`, `uniform_real_distribution`, `normal_distribution`, `bernoulli_distribution`, `discrete_distribution`

## 분포 <Badge text="C++11" />

- **분포** (distribution): 어떤 범위 안에서 수가 어떻게 퍼지는지를 나타내는 수학 공식
  - 의사 난수 엔진과 함께 써서 만들어지는 난수의 분포를 정함
  - 호출: `dist(engine)`. 분포는 엔진의 출력(부호 없는 정수)을 받아 원하는 값으로 바꿈
- 분포마다 매개변수가 있음. 수학적 의미는 여기서 다루지 않음
- 아래 목록은 분포마다 생성자 하나만 보여 줌. 생성자와 멤버 함수 전체는 레퍼런스에서

## 분포의 종류

### 균등 분포

- 범위 안의 모든 값이 같은 확률

```cpp
template <class IntType = int> class uniform_int_distribution;
// [a, b]
uniform_int_distribution(IntType a = 0,
                         IntType b = numeric_limits<IntType>::max());

template <class RealType = double> class uniform_real_distribution;
// [a, b)
uniform_real_distribution(RealType a = 0.0, RealType b = 1.0);
```

- `uniform_int_distribution`은 양 끝을 **포함**, `uniform_real_distribution`은 끝 `b`를 **포함하지 않음** <CppRef path="cpp/numeric/random/uniform_real_distribution" />

### 베르누이 분포 계열

- 첫째는 무작위 `bool`, 나머지 셋은 음이 아닌 정수를 냄(이산 확률 분포) <CppRef path="cpp/numeric/random/bernoulli_distribution" /> <CppRef path="cpp/numeric/random/binomial_distribution" /> <CppRef path="cpp/numeric/random/geometric_distribution" /> <CppRef path="cpp/numeric/random/negative_binomial_distribution" />

```cpp
// 확률 p로 true
class bernoulli_distribution;
bernoulli_distribution(double p = 0.5);

// t번 시도 중 성공 횟수
template <class IntType = int> class binomial_distribution;
binomial_distribution(IntType t = 1, double p = 0.5);

// 첫 성공 전까지의 실패 횟수
template <class IntType = int> class geometric_distribution;
geometric_distribution(double p = 0.5);

// k번 성공 전까지의 실패 횟수
template <class IntType = int> class negative_binomial_distribution;
negative_binomial_distribution(IntType k = 1, double p = 0.5);
```

### 포아송 분포 계열

- 일정 시간에 일어나는 사건의 수나, 사건 사이의 시간 같은 것을 나타냄

| 분포 | 생성자 | 내는 값 |
| --- | --- | --- |
| `poisson_distribution<IntType>` | `(double mean = 1.0)` | 음이 아닌 정수 <CppRef path="cpp/numeric/random/poisson_distribution" /> |
| `exponential_distribution<RealType>` | `(RealType lambda = 1.0)` | 양의 실수 <CppRef path="cpp/numeric/random/exponential_distribution" /> |
| `gamma_distribution<RealType>` | `(RealType alpha = 1.0, RealType beta = 1.0)` | 양의 실수 <CppRef path="cpp/numeric/random/gamma_distribution" /> |
| `weibull_distribution<RealType>` | `(RealType a = 1.0, RealType b = 1.0)` | 양의 실수 |
| `extreme_value_distribution<RealType>` | `(RealType a = 0.0, RealType b = 1.0)` | 실수 |

### 정규 분포 계열

| 분포 | 생성자 |
| --- | --- |
| `normal_distribution<RealType>` | `(RealType mean = 0.0, RealType stddev = 1.0)` <CppRef path="cpp/numeric/random/normal_distribution" /> |
| `lognormal_distribution<RealType>` | `(RealType m = 0.0, RealType s = 1.0)` |
| `chi_squared_distribution<RealType>` | `(RealType n = 1)` |
| `cauchy_distribution<RealType>` | `(RealType a = 0.0, RealType b = 1.0)` |
| `fisher_f_distribution<RealType>` | `(RealType m = 1, RealType n = 1)` |
| `student_t_distribution<RealType>` | `(RealType n = 1)` |

- 정규 분포: 평균(`mean`) 근처에 많이 몰리고 멀어질수록 드묾. 퍼진 정도가 표준 편차(`stddev`)

### 표본 분포 계열

- 직접 정한 가중치나 구간으로 분포를 만듦

```cpp
template <class IntType = int> class discrete_distribution;
discrete_distribution(initializer_list<double> weights);

template <class RealType = double> class piecewise_constant_distribution;
template <class UnaryOperation>
piecewise_constant_distribution(initializer_list<RealType> bounds,
                                UnaryOperation fw);

template <class RealType = double> class piecewise_linear_distribution;
template <class UnaryOperation>
piecewise_linear_distribution(initializer_list<RealType> bounds,
                              UnaryOperation fw);
```

- `discrete_distribution`: 인덱스 0, 1, 2, …를 각 가중치에 비례하는 확률로 고름. `{ 5, 3, 2 }`면 0은 50%, 1은 30%, 2는 20% <CppRef path="cpp/numeric/random/discrete_distribution" />
- `piecewise_constant_distribution`: 구간마다 밀도가 일정. `bounds`가 구간 경계, `fw`가 밀도를 정하는 함수 <CppRef path="cpp/numeric/random/piecewise_constant_distribution" />
- `piecewise_linear_distribution`: 구간 안에서 밀도가 직선으로 바뀜 <CppRef path="cpp/numeric/random/piecewise_linear_distribution" />

## 분포를 눈으로 보기

- 분포는 **히스토그램**으로 보면 쉬움: 난수를 많이 만들어 값마다 몇 번 나왔는지 셈
- 방법
  - `std::map<int, int>`에 값을 키로, 횟수를 값으로. `++histogram[value]`
  - 값마다 횟수에 비례하는 막대를 출력(또는 CSV로 저장해 표 계산 프로그램에서 그래프로)
- 정규 분포는 `double`을 내므로, 셀 때 정수로 바꿈(반올림 `std::lround`)

## 분포를 쓸 때 주의할 점

- 분포 객체는 가볍게 만들 수 있음. 범위가 바뀌면 새 분포를 만들거나 `param()`으로 매개변수를 바꿈
- 분포도 내부 상태를 가질 수 있음(예: 정규 분포를 값 두 개씩 만들어 하나를 남겨 두는 구현이 있음). 한 분포 객체를 여러 엔진과 섞어 쓰면 결과 재현이 어려움
  - `reset()`: 분포의 내부 상태를 지움
- 분포의 알고리즘은 표준이 정하지 않음
  - 엔진의 출력은 표준이 정하므로 어디서나 같지만, 분포를 거친 값은 표준 라이브러리마다 다를 수 있음
  - 플랫폼 사이에서 똑같은 결과가 필요하면 분포를 직접 구현

## 헷갈리기 쉬운 점

- `uniform_real_distribution<double>{ 0, 1 }`은 1도 낼 수 있다?
  - [0, 1). 1은 나오지 않음
- `uniform_int_distribution`의 두 번째 인수는 "개수"다?
  - 최댓값이고 포함됨. `{ 1, 6 }`은 1부터 6까지
- `normal_distribution<int>`로 정수 정규 분포를 만든다?
  - 실수 타입만 됨. 실수로 만든 뒤 반올림
- `discrete_distribution`의 가중치는 합이 1이어야 한다?
  - 합으로 나눠 확률이 됨. `{ 5, 3, 2 }`도 됨
- 같은 씨앗이면 어느 컴파일러에서나 분포 결과도 같다?
  - 엔진 출력만 같음. 분포 알고리즘은 구현마다 다를 수 있음

| 포아송 | `poisson`, `exponential`, `gamma`, `weibull`, `extreme_value` |
