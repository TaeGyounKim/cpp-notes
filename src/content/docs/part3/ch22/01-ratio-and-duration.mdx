## ratio: 컴파일 시간 유리수 <Badge text="C++11" />

- 유한한 유리수(분수)를 컴파일 시간에 정확하게 나타냄 <CppRef path="cpp/numeric/ratio/ratio" />
  - `<ratio>`, `std` 네임스페이스
  - 분자와 분모는 `std::intmax_t`(컴파일러가 지원하는 가장 넓은 부호 있는 정수) 타입의 컴파일 시간 상수
- 보통 객체처럼 쓰지 않음
  - `ratio`는 클래스 템플릿이고, **인스턴스 하나가 유리수 하나**. 변수가 아니라 **타입**
  - 그래서 타입 별칭으로 이름을 붙임

```cpp
using third = std::ratio<1, 3>;          // 1/3이라는 "타입"
std::intmax_t n{ third::num };           // 분자 1
std::intmax_t d{ third::den };           // 분모 3
```

- 분자와 분모는 컴파일 시간에 알아야 함. `const`가 아닌 변수로는 만들 수 없음

```cpp
std::intmax_t a{ 1 };
// using bad = std::ratio<a, 3>;         // 오류: a는 상수가 아님
const std::intmax_t b{ 1 };
using good = std::ratio<b, 3>;           // 됨
```

- 항상 **약분된 꼴**로 저장됨. `ratio<2, 6>`의 `num`은 1, `den`은 3. 부호는 분자로 옮겨짐(`ratio<1, -3>`은 -1/3)

### 연산과 비교

- 타입에 대한 계산이라 `+`, `<` 같은 연산자를 쓸 수 없음. 전용 클래스 템플릿을 씀
- 산술: `ratio_add`, `ratio_subtract`, `ratio_multiply`, `ratio_divide`
  - 결과도 `ratio` 타입(약분됨). 결과 타입 자체를 바로 쓰거나 `::type`으로 꺼냄
- 비교: `ratio_equal`, `ratio_not_equal`, `ratio_less`, `ratio_less_equal`, `ratio_greater`, `ratio_greater_equal`
  - 결과는 `std::bool_constant<true>` 또는 `std::bool_constant<false>` 타입
  - **`integral_constant`** (integral constant): 타입과 컴파일 시간 상수 하나를 담는 구조체 템플릿. `integral_constant<int, 15>`는 값 15를 담음
  - `bool_constant`는 타입이 `bool`인 `integral_constant`. 값은 `::value`

```cpp
using sum = std::ratio_add<std::ratio<1, 3>, std::ratio<1, 6>>;  // 1/2
bool less{ std::ratio_less<std::ratio<1, 6>, std::ratio<1, 3>>::value };  // true
```

- 타입이므로 `println("{}", third)`처럼 바로 출력할 수 없음. `num`, `den`을 따로 출력

### SI 접두사 별칭

- 자주 쓰는 비율에 이름이 붙어 있음

| 별칭 | 값 | 별칭 | 값 |
| --- | --- | --- | --- |
| `nano` | 1/1,000,000,000 | `deca` | 10 |
| `micro` | 1/1,000,000 | `hecto` | 100 |
| `milli` | 1/1,000 | `kilo` | 1,000 |
| `centi` | 1/100 | `mega` | 1,000,000 |
| `deci` | 1/10 | `giga` | 1,000,000,000 |

## duration: 시간 간격 <Badge text="C++11" />

- **duration** (duration): 두 시각 사이의 간격. 클래스 템플릿 `duration` <CppRef path="cpp/chrono/duration" />
- **틱** (tick) 수와 **틱 주기** (tick period)를 가짐
  - 틱 주기: 틱 하나가 몇 초인지. 컴파일 시간 `ratio`라서 1초보다 작은 값도 됨

```cpp
template <class Rep, class Period = std::ratio<1>>
class duration;
```

- `Rep`: 틱 수를 담는 타입. `int`, `long`, `double` 같은 산술 타입
- `Period`: 틱 주기. 생략하면 `ratio<1>`, 즉 1초

```cpp
using namespace std::chrono;
duration<long> a;                          // 틱 = 1초
duration<long, std::ratio<60>> b;          // 틱 = 60초(분)
duration<double, std::ratio<1, 60>> c;     // 틱 = 1/60초
duration<long long, std::milli> d;         // 틱 = 1밀리초
```

- 생성자 셋: 기본 생성자, 틱 수 하나를 받는 생성자, 다른 duration을 받는 생성자(단위 변환)
- 연산
  - 산술: `+`, `-`, `*`, `/`, `%`, `++`, `--`, `+=`, `-=`, `*=`, `/=`, `%=`
  - 비교: `==`, `<=>`
  - 단위가 다른 duration끼리도 계산과 비교가 됨. 결과는 **둘 다 정확히 나타낼 수 있는 단위**(분과 초라면 초)

| 멤버 | 하는 일 |
| --- | --- |
| `count()` | 틱 수. 타입은 `Rep` |
| `zero()` (정적) | 0인 duration |
| `min()`, `max()` (정적) | `Rep`이 나타낼 수 있는 가장 작은, 가장 큰 duration |

- `floor()`, `ceil()`, `round()`, `abs()`도 쓸 수 있음. 숫자에서와 같은 뜻 <Badge text="C++17" /> <CppRef path="cpp/chrono/duration/floor" />
- duration을 `println`으로 출력하면 단위가 붙음(`3min`, `45s`) <Badge text="C++20" />

## 단위 변환

- **세밀한 단위로**(분 → 초): 정보가 사라지지 않으므로 **암시적으로** 변환됨

```cpp
duration<long, std::ratio<60>> laps{ 10 };   // 10분
duration<long> secs{ laps };                  // 600초
```

- **거친 단위로**(초 → 분): 정수 틱이면 소수가 생길 수 있으므로 **컴파일 오류**
  - 실수 타입 `Rep`을 쓰면 됨: 30초는 `0.5`분
  - 또는 `duration_cast`를 써서 **명시적으로** 변환. 정수 나눗셈이라 버려짐(30초는 0분) <CppRef path="cpp/chrono/duration/duration_cast" />

```cpp
duration<long> s30{ 30 };
duration<double, std::ratio<60>> half{ s30 };              // 0.5분
// duration<long, std::ratio<60>> bad{ s30 };              // 오류
auto zero{ duration_cast<duration<long, std::ratio<60>>>(s30) };  // 0분
```

:::note
`duration_cast`는 0 쪽으로 버린다. 음수에서 아래로 내리려면 `floor`, 올리려면 `ceil`, 가장 가까운 값은 `round`(가운데면 짝수 쪽)를 쓴다.
:::

## 미리 정의된 duration

- `std::chrono`에 자주 쓰는 단위가 정의되어 있음
  - `Rep`의 정확한 타입은 구현마다 다르지만, 표준은 적어도 표의 비트 수를 가진 부호 있는 정수를 요구함

| 별칭 | 틱 주기 | 최소 비트 | 표준 |
| --- | --- | --- | --- |
| `nanoseconds` | `nano` | 64 | C++11 |
| `microseconds` | `micro` | 55 | C++11 |
| `milliseconds` | `milli` | 45 | C++11 |
| `seconds` | 1초 | 35 | C++11 |
| `minutes` | 60초 | 29 | C++11 |
| `hours` | 3600초 | 23 | C++11 |
| `days` | 24시간 | 25 | C++20 |
| `weeks` | 7일 | 22 | C++20 |
| `years` | 365.2425일(그레고리력 평균) | 17 | C++20 |
| `months` | 1년의 1/12 | 20 | C++20 |

- `duration<long, ratio<60>> m{ 10 };` 대신 `minutes m{ 10 };`
- `auto t{ hours{ 1 } + minutes{ 23 } + seconds{ 45 } };`의 타입은 `seconds`. `minutes{ t }`는 컴파일되지 않음
- 정수 틱이므로 거친 단위로 가는 변환은 **값과 상관없이** 컴파일 오류
  - 90초를 분으로: 1.5분이 되므로 오류
  - 60초를 분으로: 딱 1분이지만 **타입만 보고** 판단하므로 역시 오류
  - 반대 방향(분 → 초)은 항상 됨

### 리터럴 <Badge text="C++14" />

- `h`, `min`, `s`, `ms`, `us`, `ns`로 duration을 만듦 <CppRef path="cpp/chrono/operator%22%22h" />
  - `std::literals::chrono_literals` 인라인 네임스페이스에 있음
  - `using namespace std;`, `std::literals`, `std::chrono_literals`, `std::literals::chrono_literals`, `std::chrono` 중 하나면 쓸 수 있음

```cpp
using namespace std::chrono;
auto timeout{ 1500ms };
auto meeting{ 1h + 25min };
```

## hh_mm_ss <Badge text="C++20" />

- duration을 시, 분, 초, 초 미만으로 나눔 <CppRef path="cpp/chrono/hh_mm_ss" />
  - `hours()`, `minutes()`, `seconds()`, `subseconds()`: 항상 음이 아닌 값
  - `is_negative()`: 원래 duration이 음수였는지

```cpp
std::chrono::hh_mm_ss parts{ 5130s };   // 1시간 25분 30초
```

- 볼 것
  - `ratio<2, 6>`이 1/3로 약분됨. `ratio_add`, `ratio_less`
  - 분과 초를 섞어 계산하면 결과는 초(`855s`)
  - 초를 분으로: 실수 타입(`14.25min`) 또는 `duration_cast`(버림 `14min`). `ceil`은 15분
  - `1000ms / 60`은 정수 나눗셈이라 `16ms`

## 헷갈리기 쉬운 점

- `std::ratio<1, 3> r;`로 만든 `r`을 출력한다?
  - `ratio`는 타입으로 씀. `r::num`이 아니라 `std::ratio<1, 3>::num`
- 60초는 딱 1분이니 `minutes m{ 60s };`가 된다?
  - 값이 아니라 타입으로 판단. 거친 정수 단위로는 `duration_cast`
- `duration_cast<minutes>(-30s)`는 -1분이다?
  - 0 쪽으로 버려 0분. 내림은 `floor`
- `count()`는 초 단위 값이다?
  - 틱 수. `minutes{ 3 }.count()`는 3
- 분과 초를 더하면 분이 나온다?
  - 둘 다 나타낼 수 있는 더 세밀한 단위(초)

## 정리

| 요소 | 핵심 |
| --- | --- |
| `ratio<N, D>` | 컴파일 시간 유리수 타입. `num`, `den`. `ratio_add`, `ratio_less` 등 |
| `duration<Rep, Period>` | 틱 수와 틱 주기. `count()` |
| 변환 | 세밀하게는 암시적, 거칠게는 실수 `Rep`이나 `duration_cast` |
| 반올림 | `floor`, `ceil`, `round` |
| 미리 정의 | `nanoseconds`부터 `hours`, C++20의 `days`, `years` 등. 리터럴 `h`, `min`, `s`, `ms` |
| `hh_mm_ss` | 시, 분, 초로 나눔 |
