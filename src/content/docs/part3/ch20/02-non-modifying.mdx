- 다루는 것: 원소의 값이나 순서를 바꾸지 않고 순서열을 살펴 정보를 돌려주는 알고리즘
- 이 글에서 배우는 요소: 찾기, 특수 탐색기, 비교, 세기

## 찾기 알고리즘

- 1편의 `find()`, `find_if()` 말고도 여러 변형이 있음. 종류와 복잡도는 16장 3편의 표
- 모두 기본 비교로 `operator==`나 `<`를 쓰고, 다른 비교 콜백을 받는 오버로드도 있음

| 알고리즘 | 돌려주는 것 |
| --- | --- |
| `find_if_not(f, l, pred)` | 조건자가 **거짓**인 첫 원소 |
| `adjacent_find(f, l)` | 같은 값이 이웃한 첫 쌍의 앞 원소 |
| `find_first_of(f, l, f2, l2)` | 두 번째 범위의 원소 **중 하나**와 같은 첫 원소 |
| `search(f, l, f2, l2)` | 두 번째 범위와 같은 **첫** 부분 순서열의 시작 |
| `find_end(f, l, f2, l2)` | 두 번째 범위와 같은 **마지막** 부분 순서열의 시작 |
| `search_n(f, l, n, value)` | `value`가 n번 연속하는 첫 위치 |

- 모두 못 찾으면 첫 범위의 끝 반복자 `l`을 돌려줌

```cpp
std::vector levels{ 3, 4, 7, 6, 6, 2 };
auto it{ std::search_n(levels.cbegin(), levels.cend(), 2, 6) };   // 위치 3
```

:::note
같은 기능의 멤버 함수가 있는 컨테이너(예: `std::set`, `std::map`의 `find()`)에서는 멤버 함수가 더 효율적이다.
:::

### 특수 탐색기

- `search()`의 선택 매개변수로 쓸 탐색 알고리즘을 고를 수 있음 <Badge text="C++17" />. `<functional>` <CppRef path="cpp/utility/functional/boyer_moore_searcher" />
  - `default_searcher`
  - `boyer_moore_searcher`: 보이어-무어 알고리즘
  - `boyer_moore_horspool_searcher`: 보이어-무어-호스풀 알고리즘
- 뒤의 둘은 긴 글(**건초 더미**, haystack)에서 부분 문자열(**바늘**, needle)을 찾는 데 기본보다 효율적
  - 건초 더미 크기 N, 바늘 크기 M일 때 최악: 못 찾으면 O(N+M), 찾으면 O(N·M)
  - 이론상 최악일 뿐, 실제로는 건초 더미의 글자를 하나하나 보지 않고 **건너뛸** 수 있어 O(N)보다 빠름(준선형)
  - 바늘이 길수록 더 많이 건너뛰어 더 빠름
  - 호스풀 판은 초기화와 반복마다의 고정 비용이 더 작지만, 최악 복잡도가 보이어-무어보다 훨씬 클 수 있음. 쓰임새에 따라 고름

```cpp
std::boyer_moore_searcher searcher{ word.cbegin(), word.cend() };
auto found{ std::search(text.cbegin(), text.cend(), searcher) };
```

## 비교 알고리즘

- 범위 전체를 여러 방식으로 비교함. **서로 다른 컨테이너**의 순서열끼리 비교할 수 있는 것이 장점(예: `vector`와 `list`)
  - 두 범위의 같은 위치 원소들을 비교하므로 순차 컨테이너에 가장 잘 맞음

| 알고리즘 | 하는 일 |
| --- | --- |
| `equal()` | 대응하는 원소가 모두 같으면 `true` |
| `mismatch()` | 처음으로 다른 위치를 각 범위의 반복자 `pair`로 |
| `lexicographical_compare()` | 처음 다른 원소에서 첫 범위가 작거나, 첫 범위가 두 번째의 앞부분이면 `true`(사전식) |
| `lexicographical_compare_three_way()` <Badge text="C++20" /> | 사전식 삼중 비교. 비교 범주(`strong_ordering` 등) |

- `equal()`, `mismatch()`의 반복자 **셋** 판과 **넷** 판
  - 처음에는 첫 범위의 시작·끝과 두 번째 범위의 시작만 받았음. 두 범위의 원소 수가 같아야 함(두 번째가 짧으면 범위를 넘어 읽음)
  - <Badge text="C++14" /> 두 범위의 시작·끝을 모두 받는 판이 생김. 크기가 달라도 안전함
  - **늘 반복자 넷 판**을 쓰기를 권함

```cpp
std::list<int> other{ 3, 4, 9 };
bool same{ std::equal(v.cbegin(), v.cend(), other.cbegin(), other.cend()) };
auto [mine, theirs]{ std::mismatch(v.cbegin(), v.cend(),
                                   other.cbegin(), other.cend()) };
```

:::note
같은 타입의 두 컨테이너 전체를 비교한다면 알고리즘 대신 `==`, `<` 같은 연산자를 쓰면 된다. 이 알고리즘들은 부분 범위, C 스타일 배열, 서로 다른 컨테이너 타입의 순서열 등을 비교할 때 유용하다.
:::

- 범위 하나에 쓰는 비교: `all_of()`, `any_of()`, `none_of()`
  - 조건자가 모든 원소에서 참 / 하나 이상에서 참 / 어느 원소에서도 참이 아닌지
  - 빈 범위에서 `all_of()`와 `none_of()`는 `true`, `any_of()`는 `false`
  - 결과가 정해지면 바로 멈춤(단락 평가)

## 세기 알고리즘

- `count(f, l, value)`, `count_if(f, l, pred)`: 값과 같거나 조건자가 참인 원소 수 <CppRef path="cpp/algorithm/count" />

```cpp
int limit{ 4 };
auto loud{ std::count_if(v.cbegin(), v.cend(),
                         [limit](int x) { return x > limit; }) };
```

- 람다가 바깥 변수를 값으로 캡처해 기준으로 씀. 바깥 변수를 **참조로** 캡처하면 람다가 몇 번 불렸는지도 셀 수 있음(1편: 알고리즘이 람다를 복사해도 같은 변수를 가리킴)

- 볼 것
  - 각 찾기 알고리즘의 결과. `adjacent_find`와 `search_n`은 둘 다 위치 3의 6을 찾음
  - 보이어-무어 탐색기로 "quiet"의 위치
  - `vector`와 `list`를 비교: 세 번째 원소(7과 9)에서 처음 달라지고, 7 &lt; 9라 `vector`가 사전식으로 먼저
  - 람다를 참조 캡처로 세면 원소 수(6)만큼 불림

| 이 글에서 쓴 것 | 들어온 표준 | 그 이전에는 |
| --- | --- | --- |

## 헷갈리기 쉬운 점

- `adjacent_find`는 같은 값의 두 번째 원소를 돌려준다?
  - 이웃한 쌍의 **첫** 원소
- `search`와 `find_first_of`는 같다?
  - `search`는 부분 순서열 **전체**가 일치하는 곳, `find_first_of`는 원소 **하나**라도 일치하는 곳
- `equal(f, l, f2)`는 길이가 달라도 안전하다?
  - 두 번째 범위가 짧으면 범위를 넘어 읽음. 반복자 넷 판
- 빈 범위에서 `all_of`는 거짓이다?
  - 참(반례가 없음). `any_of`가 거짓
- 보이어-무어 탐색기는 늘 기본보다 빠르다?
  - 바늘이 아주 짧거나 데이터가 적으면 준비 비용이 더 클 수 있음. 측정

## 정리

| 분류 | 알고리즘 |
| --- | --- |
| 찾기 | `find`, `find_if`, `find_if_not`, `adjacent_find`, `find_first_of`, `search`, `find_end`, `search_n` |
| 특수 탐색기 | `boyer_moore_searcher`, `boyer_moore_horspool_searcher`(C++17) |
| 비교 | `equal`, `mismatch`(반복자 넷 판), `lexicographical_compare`, `..._three_way`(C++20) |
| 범위 하나 | `all_of`, `any_of`, `none_of` |
| 세기 | `count`, `count_if` |
