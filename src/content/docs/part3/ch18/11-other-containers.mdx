- 다루는 것: 엄밀한 표준 컨테이너는 아니지만 컨테이너와 관련된 것들
- 이 글에서 배우는 요소: C 스타일 배열, `string`, 스트림, `bitset`

## C 스타일 배열

- 날 포인터는 반복자에 필요한 연산을 지원하므로 진짜 **반복자**임(17장)
  - 그래서 원소의 포인터를 반복자로 써서 C 스타일 배열을 표준 컨테이너처럼 다룰 수 있음
- `size()`, `empty()`, `insert()`, `erase()` 같은 멤버 함수가 없으니 진짜 컨테이너는 아님
- 하지만 포인터로 반복자를 지원하므로 20장의 알고리즘과 이 장의 일부 멤버 함수에 쓸 수 있음
- 예: 어떤 컨테이너의 반복자 범위든 받는 `vector::insert()`로 C 배열의 모든 원소를 `vector`에 복사함

```cpp
template <typename InputIterator>
iterator insert(const_iterator position, InputIterator first, InputIterator last);
```

- `int` 배열을 원본으로 쓰면 `InputIterator`는 `int*`가 됨

```cpp
int values[10];
// ...
std::vector<int> v;
v.insert(v.end(), values, values + 10);
```

- 배열 이름만 쓰면 첫 원소의 주소로 해석됨. 끝 반복자는 끝 다음이어야 하므로 첫 원소의 주소 + 원소 수
- 포인터로 접근하지 않는 정적 C 배열이면 `std::begin()`/`std::cbegin()`, `std::end()`/`std::cend()`가 더 쉬움: `v.insert(v.end(), std::cbegin(values), std::cend(values));`
- <Badge text="C++23" /> `v.append_range(values);`가 가장 깔끔함

:::caution
`std::begin()`, `std::end()` 같은 함수는 포인터로 접근하지 않는 정적 C 스타일 배열에만 된다. 포인터를 거치거나 동적으로 할당한 C 스타일 배열에는 되지 않는다(배열 크기를 알 수 없기 때문).
:::

## 문자열

- 문자열은 문자의 순차 컨테이너로 생각할 수 있음. 실제로 C++의 `string`은 완전한 순차 컨테이너 <CppRef path="cpp/string/basic_string" />
  - 반복자를 돌려주는 `begin()`, `end()`가 있음
  - `insert()`, `push_back()`, `erase()`, `size()`, `empty()` 등 순차 컨테이너의 기본을 모두 갖춤
  - `vector`와 아주 닮아서 `reserve()`, `capacity()`도 있음
- 그래서 `vector`처럼 표준 라이브러리 컨테이너로 쓸 수 있음. 알고리즘(20장)도 그대로 적용됨
- 그 밖에도 유용한 멤버 함수와 `friend` 함수가 아주 많음. 6장에서 말한 "어수선한 인터페이스"의 좋은 예이기도 함(2장)

## 스트림

- 입출력 스트림은 원소를 **저장하지 않으므로** 전통적인 의미의 컨테이너는 아님
- 하지만 원소의 나열로 볼 수 있어 표준 컨테이너와 특성을 일부 나눔
- 스트림은 표준 라이브러리 관련 멤버 함수를 직접 제공하지 않지만, `istream_iterator`와 `ostream_iterator`로 입력·출력 스트림을 "훑을" 수 있음(17장)

## bitset

- **비트** 나열을 **고정 길이**로 추상화한 것 <CppRef path="cpp/utility/bitset" />
  - 비트는 1과 0 두 값만 가짐. 켜짐/꺼짐, 참/거짓 등으로 부름
  - `bitset`은 **설정** (set)과 **해제** (reset, unset)라는 말을 씀. 비트를 반대 값으로 **뒤집을** (flip) 수 있음
- 진짜 표준 컨테이너는 아님: 크기가 고정이고, 원소 타입으로 매개변수화되지 않고, 반복을 지원하지 않음
  - 하지만 유용한 도구 클래스라 컨테이너와 함께 다루는 경우가 많음
- <Badge text="C++23" /> `bitset`은 `constexpr` 클래스라 컴파일 시간에 쓸 수 있음

### 기본 연산

- `<bitset>`. 담을 비트 수로 매개변수화됨: `std::bitset<10>`
- 기본 생성자는 모든 비트를 0으로 초기화함. `'0'`과 `'1'` 문자로 된 문자열에서 만드는 생성자도 있음

| 멤버 | 하는 일 |
| --- | --- |
| `set(i)`, `reset(i)`, `flip(i)` | i번 비트를 켬, 끔, 뒤집음. 인수가 없으면 모든 비트. `*this`를 돌려주므로 이어 부를 수 있음 |
| `operator[](i)` | i번 비트. `const`가 아니면 **대리 객체**를 돌려주므로 `bool`을 대입하거나 `flip()`, `~`를 쓸 수 있음 |
| `test(i)` | i번 비트(범위를 벗어나면 `std::out_of_range`) |
| `count()`, `size()` | 켜진 비트 수, 전체 비트 수 |
| `any()`, `all()`, `none()` | 하나라도 / 모두 / 하나도 켜지지 않았는지 |
| `to_string()`, `to_ulong()`, `to_ullong()` | `'0'`/`'1'` 문자열, 정수로 |

- 비트 번호는 0부터
- `to_string()`의 **가장 왼쪽** 문자가 **가장 큰 번호**의 비트. 이진수를 쓰는 습관과 같음(가장 오른쪽이 1의 자리를 나타내는 0번 비트)

```cpp
std::bitset<10> bits;
bits.set(3).set(6);
bits[8] = true;
bits[9] = bits[3];
std::println("{}", bits.to_string());   // 1101001000
```

### 비트 연산자

- `bitset`은 모든 비트 연산자를 구현함: `&`, `|`, `^`, `~`, `<<`, `>>`, `&=`, `|=`, `^=`, `<<=`, `>>=`
- "진짜" 비트 나열에서처럼 동작함

```cpp
std::bitset<10> a{ "0011001100" };
std::bitset<10> b{ "0000111100" };
auto both{ a & b };   // 0000001100
both <<= 4;           // 0011000000
```

### 예: 방마다 켠 기능

- 집의 방마다 켜 둔 스마트 기능(조명 자동화, 보안 감지 등)을 비트로 기록함. 비트 번호가 기능 번호
- 자주 쓰는 조합을 **프리셋**으로 이름 붙여 둠. 이것도 `bitset`
- `SmartHome` 클래스: 프리셋 이름과 방 이름을 각각 `bitset`에 대응시키는 `map` 둘
  - `addPreset()`: `'0'`/`'1'` 문자열로 프리셋을 만듦
  - `addRoom()`: 프리셋의 비트로 방을 추가함. 없는 프리셋이면 `std::out_of_range`, 이미 있는 방이면(`emplace()`의 결과가 `false`) `std::invalid_argument`
  - `enable()`: 방의 비트 하나를 켬(`set()`)
  - `applyPreset()`: 방의 비트에 프리셋을 비트 OR(`|=`)로 합침
- 비슷한 문제: 케이블 방송 가입자마다 볼 수 있는 채널, 사용자마다 권한 플래그

## 헷갈리기 쉬운 점

- 함수 매개변수로 받은 배열 `int arr[]`에도 `std::end(arr)`를 쓸 수 있다?
  - 매개변수의 `arr`는 사실 포인터라 크기를 몰라 안 됨. `std::span`(6편)이나 크기를 따로 받음
- `bitset`의 `to_string()`에서 가장 왼쪽이 0번 비트다?
  - 가장 왼쪽이 가장 **큰** 번호. 0번은 가장 오른쪽
- `bitset`을 범위 기반 `for` 문으로 훑을 수 있다?
  - 반복자가 없음. `size()`까지 인덱스로 `test(i)`나 `[i]`
- `bitset<N>`의 N을 실행 중에 정할 수 있다?
  - 템플릿 인수라 컴파일 시간 상수여야 함. 실행 중에 크기가 바뀌면 `vector<bool>`이나 `vector<unsigned char>`(4편)

## 정리

| 요소 | 핵심 |
| --- | --- |
| C 배열 | 포인터가 반복자. `std::begin`/`std::end`(정적 배열만), C++23 `append_range` |
| `string` | 완전한 순차 컨테이너. `vector`와 닮음(`reserve`, `capacity`) |
| 스트림 | 저장하지 않음. 스트림 반복자로 훑음 |
| `bitset<N>` | 고정 길이 비트. `set`/`reset`/`flip`/`test`/`count`, 비트 연산자, `to_string` |

## 18장을 마치며

- 표준 라이브러리 컨테이너를 차례로 다룸
  - 순차 컨테이너(`vector`, `deque`, `list`, `forward_list`, `array`)와 순차 뷰(`span`, `mdspan`)
  - 컨테이너 어댑터(`queue`, `priority_queue`, `stack`)
  - 정렬된 연관 컨테이너(`map`, `multimap`, `set`, `multiset`), 해시 테이블, 평평한 연관 컨테이너 어댑터
  - 그 밖에 C 배열, `string`, 스트림, `bitset`
- 직접 자료 구조를 짜는 대신 알맞은 표준 컨테이너를 고르는 것이 대개 더 빠르고 안전함. 고민되면 `vector`부터, 성능이 중요하면 측정
- 다음 장(19장): 함수 포인터, 함수 객체, 람다 표현식
