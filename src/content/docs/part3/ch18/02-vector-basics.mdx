## vector 개요

- `std::vector`는 C 스타일 배열과 비슷함. 원소가 **연속된 메모리**에 각자의 "칸"에 저장됨 <CppRef path="cpp/container/vector" />
  - 첨자로 접근하고, 끝에 새 원소를 더하거나 아무 곳에나 끼워 넣을 수 있음
  - 넣기·지우기는 보통 선형 시간이지만 **끝에서는** 분할 상환 상수 시간(4편)
  - 개별 원소의 임의 접근은 상수 시간
- `<vector>`에 정의된 클래스 템플릿. 타입 매개변수는 원소 타입과 할당자 타입

```cpp
template <typename T, typename Allocator = std::allocator<T>> class vector;
```

- 할당자 매개변수는 기본값이면 거의 모든 경우에 충분함(25장)
- `std::vector`는 `std::string`처럼 `constexpr`임 <Badge text="C++20" />. 컴파일 시간 계산과 `constexpr` 함수·클래스 구현에 쓸 수 있음(9장)

## 고정 길이로 쓰기

- 원소 수를 받는 생성자로 만들고, 오버로드된 `operator[]`로 원소를 읽고 고침

```cpp
std::vector<double> scores(10);   // double 10개(0.0으로)
scores[0] = 72.5;
```

- `operator[]`로 범위 밖에 접근하면 **정의되지 않은 동작**. 컴파일러가 어떻게 할지 정함
  - 예: 어떤 구현은 디버그 빌드에서는 실행 시간 오류를 보이고 릴리스 빌드에서는 성능을 위해 검사하지 않음. 설정으로 바꿀 수 있음

:::caution
진짜 배열의 첨자처럼 `vector`의 `operator[]`도 범위 검사를 하지 않는다.
:::

- 그 밖의 원소 접근
  - `at(i)`: `operator[]`와 같지만 범위를 검사하고, 벗어나면 `std::out_of_range` 예외를 던짐
  - `front()`, `back()`: 첫 원소, 마지막 원소의 참조. **빈** 컨테이너에 부르면 정의되지 않은 동작
- 모든 원소 접근은 **상수 시간**
- `const`인 `vector`에 `operator[]`를 부르면 `const` 원소의 참조를 돌려주므로 대입할 수 없음(15장의 기법)
- `for (auto& s : scores)`처럼 범위 기반 `for` 문으로 원소를 고칠 때는 `auto&`를 씀. `auto`면 복사본이 바뀜

## 늘어나는 배열로 쓰기

- `vector`의 진짜 힘은 **알아서 커지는** 것
- 기본 생성자로 원소 0개짜리를 만들고, `push_back()`으로 끝에 더함. 새 원소의 공간은 `push_back()`이 마련함

```cpp
std::vector<double> scores;          // 원소 0개
double value;
while (std::cin >> value && value >= 0) {
    scores.push_back(value);
}
```

- `size()`: 원소 수. `empty()`: 원소가 없는지

## 출력하기

- <Badge text="C++23" /> `std::format()`과 `print()` 함수로 컨테이너 전체를 한 문장에 서식화·출력함(2장)
  - 모든 순차 컨테이너, 컨테이너 어댑터, 연관 컨테이너에 됨

```cpp
std::vector values{ 1.1, 2.2, 3.3 };
std::println("{}", values);     // [1.1, 2.2, 3.3]
std::println("{:n}", values);   // 1.1, 2.2, 3.3   (n: 대괄호 없이)
```

- 지원하지 않는 컴파일러에서는 범위 기반 `for` 문으로 하나씩 출력함

## 생성자

| 코드 | 결과 |
| --- | --- |
| `std::vector<int> v;` | 원소 0개 |
| `std::vector<int> v(10);` | 원소 10개, **영 초기화**(0) |
| `std::vector<int> v(10, 100);` | 100이 10개 |
| `std::vector<std::string> v(3, "hi");` | `"hi"`가 3개 |
| `std::vector<int> v{ 1, 2, 3 };` | 원소 1, 2, 3(초기화 리스트) |
| `std::vector v{ 1, 2, 3 };` | 같음. 클래스 템플릿 인수 추론 <Badge text="C++17" /> |

- **영 초기화** (zero-initialization): 객체는 기본 생성자로 만들고, 기본 정수 타입은 0, 부동소수점은 0.0, 포인터는 `nullptr`로
- 직접 만든 클래스도 원소가 될 수 있음: `std::vector<Element> elements;`
- 자유 공간에 만들 수도 있음: `auto p{ std::make_unique<std::vector<Element>>(10) };`

### 소괄호와 중괄호

- 보통은 생성자를 부를 때 중괄호 초기화를 쓰면 되지만, `vector`는 조심해야 함
  - 중괄호는 **초기화 리스트 생성자**를 먼저 고름

```cpp
std::vector<int> a(10, 100);   // 100이 10개
std::vector<int> b{ 10, 100 }; // 원소 둘: 10과 100
std::vector<int> c(10);        // 0이 10개
std::vector<int> d{ 10 };      // 원소 하나: 10
```

## 복사와 대입

- `vector`는 객체의 복사본을 담고, 소멸자는 각 원소의 소멸자를 부름
- 복사 생성자와 대입 연산자는 모든 원소를 **깊은 복사**함
  - 그래서 함수에 넘길 때는 값이 아니라 (`const`) 참조로 넘김
- `assign()`: 현재 원소를 모두 지우고 새 원소들로 채움. `vector`를 다시 쓸 때 유용

```cpp
std::vector<int> v(10);   // 0이 10개
v.assign(5, 100);         // 100이 5개
v.assign({ 1, 2, 3, 4 }); // 1, 2, 3, 4
```

- `swap()`: 두 `vector`의 내용을 **상수 시간**에 맞바꿈. 원소를 하나하나 옮기지 않고 내부 버퍼만 바꿈

## 비교

- `==`, `!=`, `<`, `>`, `<=`, `>=` 여섯 비교 연산자를 제공함(C++20부터는 `==`와 `<=>`로 정의되고 나머지는 거기서 만들어짐)
- 두 `vector`가 **같다**: 원소 수가 같고 대응하는 원소가 모두 같음
- **사전식** 비교: 앞에서부터 대응하는 원소를 비교해 처음 다른 원소로 결정. 한쪽이 다른 쪽의 앞부분이면 짧은 쪽이 작음
- `==`, `!=`는 원소에 `operator==`가, `<` 등은 원소에 `operator<`(C++20부터는 `<=>`로도)가 필요함. 직접 만든 클래스를 담는다면 이 연산자를 씀

## 헷갈리기 쉬운 점

- `std::vector<int> v{ 10 };`은 원소 10개다?
  - 원소 하나(값 10). 10개는 `v(10)`
- `operator[]`도 범위를 검사한다?
  - 검사하지 않음. 정의되지 않은 동작. 검사가 필요하면 `at()`
- 빈 `vector`의 `front()`는 예외를 던진다?
  - 정의되지 않은 동작. 먼저 `empty()`를 확인
- `swap()`은 원소를 하나씩 맞바꾼다?
  - 내부 버퍼만 바꿔 상수 시간
- `for (auto s : v) { s *= 2; }`로 원소를 고칠 수 있다?
  - `s`는 복사본. `auto&`를 씀

## 정리

| 요소 | 핵심 |
| --- | --- |
| 원소 접근 | `[]`(검사 없음), `at()`(예외), `front()`, `back()`. 상수 시간 |
| 늘리기 | `push_back()`. 끝은 분할 상환 상수 시간 |
| 생성자 | `(n)`, `(n, 값)`, `{ 원소들 }`. 소괄호와 중괄호가 다름 |
| 복사·대입 | 깊은 복사. 함수에는 참조로. `assign()`, `swap()`(상수 시간) |
| 비교 | `==`(크기와 원소), `<`(사전식) |
| 출력 | C++23 `println("{}", v)`, `{:n}` |

<details>
<summary>`std::vector<int> v(5);` 다음에 `v.push_back(1);`을 하면 `v`는 어떻게 되는가?</summary>

- `[0, 0, 0, 0, 0, 1]`. `(5)`는 이미 원소 5개를 만들었고 `push_back`은 그 뒤에 더함. 미리 공간만 잡으려면 `reserve(5)`(4편)

</details>

<details>
<summary>사용자가 준 첨자로 원소를 읽을 때 `operator[]`와 `at()` 중 무엇을 쓰는가?</summary>

- 첨자가 올바른지 보장할 수 없으므로 `at()`을 쓰고 `std::out_of_range`를 처리함. 또는 먼저 `i < v.size()`를 검사하고 `[]`

</details>

<details>
<summary>`std::vector<int>{ 1, 2, 3 } < std::vector<int>{ 1, 3 }`의 결과는?</summary>

- 참. 두 번째 원소에서 2 &lt; 3으로 결정되며 길이는 상관없음

</details>
