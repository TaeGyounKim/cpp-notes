- 다루는 것: 문자열 처리용 작은 언어인 **정규식** (regular expression)의 문법. C++에서 쓰는 법은 3~4편
- 이 글에서 배우는 요소: 정규식의 쓰임새와 용어, 지원하는 문법, ECMAScript 문법의 각 요소, 날 문자열 리터럴

## 정규식

- `<regex>`에 정의된 표준 라이브러리의 강력한 문자열 기능 <CppRef path="cpp/regex" />
  - 문자열 처리를 위한 특별한 작은 언어를 지원함. 처음에는 복잡해 보이지만 익히면 문자열 다루기가 쉬워짐
- 쓰임새

| 일 | 예 |
| --- | --- |
| **검증** (validation) | 입력 문자열이 올바른 형식인가? 예: 올바른 전화번호인가 |
| **판별** (decision) | 입력이 어떤 종류의 문자열인가? 예: JPEG 파일 이름인가 PNG 파일 이름인가 |
| **파싱** (parsing) | 입력에서 정보를 꺼냄. 예: 날짜에서 연, 월, 일 |
| **변환** (transformation) | 부분 문자열을 찾아 새로 서식화한 문자열로 바꿈. 예: 모든 "C++23"을 "C++"로 |
| **반복** (iteration) | 부분 문자열이 나오는 곳을 모두 찾음. 예: 입력에서 전화번호를 모두 꺼냄 |
| **토큰화** (tokenization) | 구분자 집합으로 문자열을 나눔. 예: 공백, 쉼표, 마침표로 나눠 낱말을 꺼냄 |

- 이런 일을 직접 짤 수도 있지만, 문자열을 올바르고 안전하게 처리하는 코드는 까다로우므로 정규식 기능을 쓰기를 권함

### 용어

| 용어 | 뜻 |
| --- | --- |
| **패턴** (pattern) | 실제 정규식. 문자열로 나타냄 |
| **일치** (match) | 정규식이 주어진 순서열 [first, last)의 **모든** 문자와 일치하는지 |
| **찾기** (search) | 주어진 순서열 안에 정규식과 일치하는 **부분 문자열이 있는지** |
| **바꾸기** (replace) | 순서열에서 부분 문자열을 찾아, **치환 패턴**으로 만든 새 부분 문자열로 바꿈 |

### 지원하는 문법

- 정규식 문법은 여러 가지. C++이 지원하는 것
  - **ECMAScript**: ECMA-262로 표준화된 스크립트 언어 ECMAScript의 문법. JavaScript 등의 핵심
  - **basic**: POSIX 기본 문법
  - **extended**: POSIX 확장 문법
  - **awk**: POSIX `awk` 도구의 문법
  - **grep**: POSIX `grep` 도구의 문법
  - **egrep**: `-E` 옵션을 준 `grep`의 문법
- 이미 아는 문법이 있으면 정규식 라이브러리에 그 문법을 쓰라고 알려 주고(`syntax_option_type`) 바로 씀
- C++의 기본 문법은 **ECMAScript**. 가장 강력하기도 함. 이 사이트는 ECMAScript만 다룸

:::note
정규식을 처음 접한다면 기본 ECMAScript 문법을 쓴다.
:::

## ECMAScript 문법

- 정규식 패턴은 일치시키고 싶은 것을 나타내는 문자 나열
- 다음 **특수 문자**를 빼고 모든 문자는 자기 자신과 일치함

```text
^ $ \ . * + ? ( ) [ ] { } |
```

- 특수 문자 자체와 일치시키려면 `\`로 이스케이프함: `\[`, `\.`, `\*`, `\\`

### 앵커

- `^`, `$`: **앵커** (anchor)
  - `^`는 줄 끝 문자 바로 뒤의 위치, `$`는 줄 끝 문자의 위치와 일치함
  - 기본적으로 문자열의 시작과 끝에도 일치함(끌 수 있음)
- 예: `^test$`는 문자열 `test`하고만 일치하고, `1test`, `test2`, `test abc`처럼 어딘가에 test를 포함한 문자열과는 일치하지 않음

### 와일드카드, 선택, 그룹

- **와일드카드** `.`: 줄바꿈 문자를 뺀 아무 문자 하나와 일치함. `a.c`는 `abc`, `a5c`와 일치하고 `ab5c`, `ac`와는 일치하지 않음
- **선택** `|`: "또는" 관계. `a|b`는 `a`나 `b`와 일치함
- **그룹** `()`: 하위 표현식을 표시함. **캡처 그룹** (capture group)이라고도 함
  - 원래 문자열의 개별 부분 순서열을 식별함. 표시한 하위 표현식은 결과로 돌려받음
  - 예: `(.)(ab|cd)(.)`로 `1cd4`를 찾으면 일치 결과가 넷: 전체 일치 `1cd4`와 세 하위 표현식 `1`, `cd`, `4`
  - 아래의 역참조, 그리고 바꾸기(4편)에도 씀

### 수량자

- 정규식의 일부를 반복하는 **수량자** (quantifier) 넷

| 수량자 | 뜻 | 예 |
| --- | --- | --- |
| `*` | 앞의 것을 0번 이상 | `a*b`: `b`, `ab`, `aab`, … |
| `+` | 앞의 것을 1번 이상 | `a+b`: `ab`, `aab`, …(`b`는 아님) |
| `?` | 앞의 것을 0번 또는 1번 | `colou?r`: `color`, `colour` |
| `{n}`, `{n,}`, `{n,m}` | 정확히 n번 / n번 이상 / n번에서 m번 | `b{3,4}`: `bbb`, `bbbb` |

- 이 수량자들은 **탐욕적** (greedy): 정규식의 나머지가 일치할 수 있는 한 **가장 길게** 일치함
- 뒤에 `?`를 붙이면(`*?`, `+?`, `??`, `{...}?`) 탐욕적이지 않음: 나머지가 일치하는 한 **가장 적게** 반복함
- 예: `aaabbb`에 대해

| 정규식 | 하위 일치 |
| --- | --- |
| 탐욕적 `(a+)(ab)*(b+)` | `"aaa"` `""` `"bbb"` |
| 탐욕적이지 않음 `(a+?)(ab)*(b+)` | `"aa"` `"ab"` `"bb"` |

### 우선순위

- 수식처럼 정규식 요소에도 우선순위가 있음
  - `b` 같은 요소가 기본 구성 단위
  - `+`, `*`, `?`, `{...}` 같은 수량자가 왼쪽 요소에 가장 강하게 붙음: `b+`
  - 이어 붙이기(`ab+c`)가 그다음
  - 선택 `|`이 가장 마지막
- 예: `ab+c|d`는 `abc`, `abbc`, …와 `d`에 일치함
- 괄호로 우선순위를 바꿈: `ab+(c|d)`는 `abc`, `abbc`, …, `abd`, `abbd`, …
  - 하지만 괄호는 캡처 그룹도 만듦. 캡처 그룹 없이 우선순위만 바꾸려면 `(?:...)`: `ab+(?:c|d)`

### 문자 집합

- `(a|b|c|...|z)`는 길고 캡처 그룹도 만듦. 문자 집합이나 범위를 나타내는 문법이 따로 있음
- **문자 집합**: 대괄호 안에 씀. `[abc]`는 `a`, `b`, `c` 중 하나
  - 첫 문자가 `^`이면 "그것들 말고 아무거나": `ab[^cde]`는 `abf`, `abp` 등과 일치하고 `abc`, `abd`, `abe`와는 일치하지 않음
  - `^`, `[`, `]` 자체는 이스케이프함: `[\[\^\]]`
- **범위**: `[a-zA-Z]`는 a부터 z, A부터 Z까지의 모든 글자. 하이픈 자체는 이스케이프함: `[a-zA-Z\-]+`는 하이픈이 든 낱말도 포함

### 문자 클래스

- 특정 종류의 문자를 나타내는 **문자 클래스**: `[:이름:]`. 문자 집합 **안에서** 씀: `[[:alpha:]]*`
  - 어떤 클래스가 있는지와 정확한 뜻은 로캘(1편)에 따라 다르지만, 아래 이름은 늘 인식됨(표는 "C" 로캘 기준)

| 클래스 | 뜻 |
| --- | --- |
| `digit`, `d` | 숫자 0~9 |
| `xdigit` | 숫자와 16진수에 쓰는 글자 a부터 f, A부터 F |
| `alpha` | 글자. "C" 로캘에서는 영어 소문자와 대문자 |
| `alnum`, `w` | `alpha`와 `digit`을 합친 것 |
| `lower`, `upper` | 소문자, 대문자(로캘에 해당하면) |
| `blank` | 한 줄 안에서 낱말을 나누는 공백 문자. "C" 로캘에서는 공백과 탭 |
| `space`, `s` | 공백 문자. "C" 로캘에서는 공백, `\t`, `\n`, `\r`, `\v`, `\f` |
| `print` | 출력되는 문자(제어 문자의 반대). 글자, 숫자, 구두점, 공백 등 |
| `cntrl` | 제어 문자. 출력 위치를 차지하지 않음. 예: `\f`, `\n`, `\r` |
| `graph` | 그래픽 표현이 있는 문자. 공백을 뺀 `print` |
| `punct` | 구두점. `graph` 중 `alnum`이 아닌 것. 예: `!`, `#`, `@`, `}` |

- 숫자처럼 흔한 클래스에는 짧은 표기가 있음. `[0-9]+`, `[[:digit:]]+`, `[[:d:]]+`, `\d+`는 모두 같음

| 이스케이프 | 같은 뜻 |
| --- | --- |
| `\d` / `\D` | `[[:d:]]` / `[^[:d:]]` |
| `\s` / `\S` | `[[:s:]]` / `[^[:s:]]` |
| `\w` / `\W` | `[_[:w:]]` / `[^_[:w:]]` |

- 예
  - `Test[5-8]`: `Test5`, `Test6`, `Test7`, `Test8`
  - `[[:lower:]]`: 소문자 하나. `[^[:lower:]]`: 소문자가 아닌 문자 하나
  - `[[:lower:]5-7]`: 소문자 하나 또는 숫자 5, 6, 7

### 단어 경계

- **단어 경계** `\b`, 단어 경계가 아닌 곳 `\B`
  - 낱말의 첫 문자: 단어 문자이고 그 앞 문자는 단어 문자가 아님. **단어 문자**는 글자, 숫자, 밑줄("C" 로캘에서 `[A-Za-z0-9_]`)
  - 낱말의 끝: 단어 문자가 아닌 문자이고 그 앞 문자는 단어 문자
  - 원본 문자열의 첫 문자가 단어 문자면 문자열의 시작(`regex_constants::match_not_bow`로 끌 수 있음. bow는 beginning-of-word)
  - 원본 문자열의 마지막 문자가 단어 문자면 문자열의 끝(`match_not_eow`로 끔. eow는 end-of-word)

### 역참조

- **역참조** (back reference): 정규식 안에서 캡처 그룹을 다시 가리킴. `\n`은 n번째 캡처 그룹(n > 0)
- 예: `(\d+)-.*-\1`은 다음 형식의 문자열과 일치함
  - 숫자 하나 이상을 캡처 그룹 `(\d+)`로 잡고
  - 대시 `-`, 아무 문자 0개 이상 `.*`, 대시 `-`
  - 첫 캡처 그룹과 **같은** 숫자 `\1`
  - `123-abc-123`, `1234-a-1234`와는 일치하고 `123-abc-1234`, `123-abc-321`과는 일치하지 않음

### 전방 탐색

- **긍정 전방 탐색** `(?=패턴)`, **부정 전방 탐색** `(?!패턴)`
  - 뒤따르는 문자들이 패턴과 일치해야(긍정) / 일치하지 않아야(부정) 하지만, 그 문자들을 아직 **소비하지 않음**
  - `a(?!b)`: 뒤에 b가 오지 않는 a. `a(?=b)`: 뒤에 b가 오는 a(b는 일치 결과에 포함되지 않음)
- 실용 예: 소문자, 대문자, 구두점이 각각 하나 이상 있고 8자 이상인 입력. 비밀번호 규칙을 강제할 때

```text
(?=.*[[:lower:]])(?=.*[[:upper:]])(?=.*[[:punct:]]).{8,}
```

## 정규식과 날 문자열 리터럴

- 정규식에는 C++ 일반 문자열 리터럴에서 이스케이프해야 하는 특수 문자가 많음
  - 정규식 `\d`를 일반 리터럴로 쓰면 `"\\d"`. 아니면 C++ 컴파일러가 `\d`를 해석하려 함(GCC는 알 수 없는 이스케이프라고 경고)
  - 역슬래시 하나와 일치시키려면: 정규식 문법에서 `\\`, 그것을 다시 C++ 리터럴로 이스케이프해 `"\\\\"`
- **날 문자열 리터럴**(2장)로 읽기 쉽게 씀. `R"(`로 시작해 `)"`로 끝나고 그 사이가 정규식 그대로

```cpp
std::regex a{ "( |\\n|\\r|\\\\)" };   // 공백, 줄바꿈, 캐리지 리턴, 역슬래시
std::regex b{ R"(( |\n|\r|\\))" };    // 같은 정규식을 날 문자열로
```

- 날 문자열에서도 정규식 자체의 이스케이프(`\\`)는 필요함

## 흔한 정규식

- 올바른 정규식을 쓰는 일이 늘 쉽지는 않음
- 비밀번호, 전화번호, IP 주소, 이메일 주소, 신용카드 번호, 날짜처럼 흔한 패턴은 직접 쓰지 않아도 됨
  - 미리 만든 패턴을 모아 둔 웹 사이트가 많음(regexr.com, regex101.com 등). 온라인으로 시험해 보고 코드에 쓸 수 있음

- 볼 것
  - 각 패턴이 입력 문자열 **전체**와 일치하는지(O/x). `regex_match`는 전체 일치(3편)
  - `ab+c|d`는 `abd`와 일치하지 않지만 괄호로 묶은 `ab+(?:c|d)`는 일치
  - 역참조 `\1`은 앞에서 잡은 숫자와 같아야 함

  - 일반 리터럴은 역슬래시를 두 번, 날 문자열은 한 번

## 헷갈리기 쉬운 점

- `.`은 줄바꿈과도 일치한다?
  - 줄바꿈 문자를 뺀 문자 하나
- 괄호는 우선순위만 바꾼다?
  - 캡처 그룹도 만듦. 캡처 없이 묶으려면 `(?:...)`
- `[:digit:]`만 쓰면 숫자 하나와 일치한다?
  - 문자 클래스는 문자 집합 안에서: `[[:digit:]]`
- `a+`와 `a+?`는 같은 문자열에 일치한다?
  - 같은 입력 전체와 일치하더라도, 하위 일치(캡처 그룹)에 잡히는 부분이 다름
- `"\d"`로 써도 된다?
  - C++ 리터럴의 알 수 없는 이스케이프. `"\\d"`나 `R"(\d)"`

## 정리

| 요소 | 문법 |
| --- | --- |
| 앵커 | `^`, `$` |
| 와일드카드·선택 | `.`, `\|` |
| 그룹 | `(...)` 캡처, `(?:...)` 비캡처 |
| 수량자 | `*`, `+`, `?`, `{n,m}`. 뒤에 `?`면 탐욕적이지 않음 |
| 문자 집합 | `[abc]`, `[^abc]`, `[a-z]`, `[[:alpha:]]`, `\d`, `\s`, `\w` |
| 경계·참조 | `\b`, `\B`, 역참조 `\1` |
| 전방 탐색 | `(?=...)`, `(?!...)` |
| C++에서 | 날 문자열 `R"(...)"`로 이스케이프를 줄임 |

## 복습 질문

<details>
<summary>"2026-11-23" 같은 날짜(연 네 자리, 월·일 두 자리)를 검증하고 연, 월, 일을 그룹으로 잡는 패턴은?</summary>

```text
(\d{4})-(\d{2})-(\d{2})
```

- 월이 01~12인지까지 보려면 `(0[1-9]|1[0-2])`처럼 좁힘

</details>

<details>
<summary>`.jpg`나 `.png`로 끝나는 파일 이름(대소문자 구분)을 판별하는 패턴은?</summary>

```text
.+\.(jpg|png)
```

- 점은 이스케이프해야 아무 문자가 아니라 마침표와 일치함

</details>

<details>
<summary>`"<b>굵게</b> 또 <b>굵게</b>"`에서 `<b>.*</b>`와 `<b>.*?</b>`는 각각 무엇과 일치하는가(찾기)?</summary>

- `.*`는 탐욕적이라 첫 `<b>`부터 마지막 `</b>`까지 전체
- `.*?`는 탐욕적이지 않아 첫 `<b>굵게</b>`만

</details>
